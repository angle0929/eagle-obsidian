1. 结缔组织
	1. 细胞外基质（大量）：结缔组织细胞分泌产生的呈丝状的纤维和无定形基质，以及不断循环更新的组织液
	2. 细胞（多种、少量）
	3. 分类
		1. 固有结缔组织（胶体状基质）
			```
			1.细胞数量少，种类多
			2.细胞外基质数量多
			3.有血管、神经（与软骨、骨和血液的重要区别）
			```
			1. 疏松结缔组织
			2. 致密结缔组织
			3. 脂肪组织$\rightarrow$==脂肪是结缔组织==
			4. 网状组织
		2. 软骨组织（固体状基质）
		3. 血液（液体状基质）
	4. 作用：连接、支持、保护、贮存营养、物质运输
	5. 演化由来：胚胎时期的间充质，无纤维
		1. 无定形基质
		2. 间充质细胞
			1. 星状，细胞间以突起互连成网
			2. 核大，呈卵圆形，核仁明显
			3. 细胞质呈弱嗜碱性
			4. 细胞分化程度低，增值分化能力强、成体结缔组织内仍存留少量的未分化间充质细胞
			5. 功能：分化、连接、营养、保护

# 疏松结缔组织（loose connective tissue）/蜂窝组织(areolar tissue)

1. 细胞种类多，数量少

| 细胞名称            | 形状 / 形态特点（光镜 L.M + 电镜 E.M）                                              | 细胞核特点                                   | 细胞质特点             | 核心作用                                                                                                                                                                                           | 显著特征                                  | 分布                                  |
| --------------- | ----------------------------------------------------------------------- | --------------------------------------- | ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------- | ----------------------------------- |
| 成纤维细胞（功能活跃）     | **光镜**：胞体大，扁平多突起；<br><br>**电镜**：粗面内质网、游离核糖体、高尔基复合体发达                    | 大、卵圆形、**着色浅**，核仁明显                      | 弱嗜碱性              | 1. 合成和分泌**胶原纤维、弹性纤维、网状纤维**及**基质**成分$\rightarrow$常附着在胶原纤维上<br>2. 由于所合成的蛋白质以芽生的方式形成小囊泡通过胞吐分泌到细胞外，故细胞质中无明显的分泌颗粒，称其为**持续性蛋白质分泌细胞**<br>3. 可分泌多种**生长因子**，调控各种细胞的增殖与功能                                | 疏松结缔组织中**数量最多、最主要**的细胞                |                                     |
| 纤维细胞（成纤维细胞静止状态） | **光镜**：胞体较小，呈**长梭形**，突起少；<br><br>**电镜**：粗面内质网少，高尔基复合体不发达                | 小、细长、染色深                                | 弱嗜酸性              | 功能静止状态，创伤等刺激下可**逆转为成纤维细胞**，并分裂、增殖，向受损部位迁移，产生细胞外基质，形成瘢痕组织                                                                                                                                       |                                       |                                     |
| 巨噬细胞            | **光镜**：形态不规则，有**伪足**；<br><br>**电镜**：表面有皱褶、微绒毛和少数球形隆起，含大量溶酶体、吞噬体、吞饮泡和残余体 | 小、圆形或肾形、染色深                             | 嗜酸性，内含空泡、异物颗粒     | 1. 吞噬异物：特异性吞噬作用、非特异性吞噬作用<br>2. 抗原呈递作用：形成**抗原肽-MHC分子复合物**，呈递到细胞表面$\rightarrow$为机体主要的**抗原呈递细胞**<br>3. 分泌功能：分泌溶菌酶、补体（参与炎症反应、对病原微生物的溶解）、多种细胞因子（如白细胞介素-1，刺激骨髓中白细胞增殖并释放入血）<br>4. **趋化性**：巨噬细胞发挥功能的前提 | 1. 来源于**血液中的单核细胞**，是一种免疫细胞<br>2. 卡红染色 |                                     |
| 浆细胞             | **光镜**：圆形或卵圆形；<br><br>**电镜**：大量**环形平行排列**粗面内质网、发达高尔基复合体                 | 圆形、**多偏于一侧**，染色质**呈粗条块状，从核中心向核膜呈辐射状分布** | 强嗜碱性，**核旁有淡染区**   | 合成和分泌**抗体（免疫球蛋白）**                                                                                                                                                                             | 来源于 B 淋巴细胞，参与体液免疫                     | 脾、淋巴结以及消化管、呼吸道等粘膜的结缔组织或淋巴组织内及慢性炎症部位 |
| 肥大细胞            | **光镜**：圆形 / 卵圆形，体积较大；<br><br>**电镜**：胞质内含膜包颗粒                            | 小而圆，**居中**                              | 充满**粗大嗜碱性、异染性颗粒** | 释放组胺、肝素等，**参与过敏反应**                                                                                                                                                                            | 颗粒易溶于水，甲苯胺蓝染色呈紫红色                     |                                     |
| 脂肪细胞            | **光镜**：球形 / 多边形，体积大；<br><br>**电镜**：胞质内有单个大脂滴                            | 扁平、**被挤至细胞一侧**                          | 呈**戒指状**，仅存少量薄层胞质 | 合成、储存脂肪，参与脂质代谢                                                                                                                                                                                 | 典型**单泡脂肪细胞**，HE 染色呈空泡状                |                                     |
| 未分化间充质细胞        | **光镜**：梭形，类似成纤维细胞；<br><br>**电镜**：细胞器不发达                                 | 椭圆形，核仁明显                                | 弱嗜碱性              | 可分化为成纤维细胞、内皮细胞、平滑肌细胞等                                                                                                                                                                          | 结缔组织的**干细胞**，多向分化潜能                   |                                     |
| 白细胞（游走细胞）       | 形态多样，可做变形运动穿出血管                                                         | 形态依细胞类型不同                               | 各异                | 参与免疫、炎症反应                                                                                                                                                                                      | 从血液迁移至结缔组织，游走存在                       |                                     |
>[!tip]
>1. 浆细胞细胞核旁浅染色区是因为细胞质内几乎充满呈环形平行排列的粗面内质网，粗面内质网上有核糖体（rRNA），核酸是嗜碱性物质，在HE染色中呈蓝紫色
2. 细胞外基质数量多
	1. 基质：均质无定形

| 核心属性          | 组成成分                       | 具体功能                                                         |
| ------------- | :------------------------- | ------------------------------------------------------------ |
| 整体特征          | 无定形的均质胶态物质，是细胞外基质的重要组成     | ①构成疏松结缔组织的胶状支架<br><br>②形成分子筛结构，限制病原体扩散<br><br>③作为内环境，参与物质交换  |
| 蛋白多糖          | 以透明质酸为主干，结合蛋白多糖亚单位形成试管刷样结构 | 构成分子筛的核心框架，使基质具有黏性和弹性                                        |
| 结构性糖蛋白（多黏糖蛋白） | 无具体细分成分描述                  | 参与细胞间的黏附与细胞的迁移过程                                             |
| 组织液           | 由血浆从毛细血管渗出形成，在分子筛网孔中流动     | ①为结缔组织细胞提供营养、氧气，运走代谢废物<br><br>②维持细胞的正常生理环境<br><br>③参与机体的物质循环 |
		1. 作用（补充）
			1. 构成内环境
	2. 纤维
