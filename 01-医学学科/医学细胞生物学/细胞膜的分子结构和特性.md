# 细胞膜的基本成分

1. 膜酯
	1. 磷脂（≥膜酯的50%）
		1. 甘油磷脂
			1. 骨架：甘油
			2. e.g. 磷脂酰乙醇胺、磷脂酰丝氨酸、磷脂酰胆碱（卵磷酸）
		2. 鞘磷脂
			1. 骨架：鞘氨醇
			2. 头部：磷酸胆碱
		3. 哺乳动物细胞膜上占优势的4种磷脂
			1. 磷脂酰乙酸胺
			2. 磷脂酰丝氨酸
			3. 链酯酰胆碱
			4. 鞘磷脂
	2. 胆固醇（动物，约占膜脂的20%）
		1. 构成：
			1. 羟基：
				1. 连在固醇环上
				2. 紧靠磷脂的极性头部
			2. 固醇环（甾环结构）
				1. 刚性
				2. 四元环
			3. 烃链
		2. 作用：
			1. 极强细胞膜结构的稳定性
			2. 调节膜的流动性
	3. 糖脂
		1. 组成
			1. 脂类
				1. 细胞和植物细胞：==几乎都==是甘油磷脂的衍生物，一般为磷脂酰胆碱衍生的糖脂
				2. 动物细胞：==几乎都==是鞘氨醇衍生的糖脂$\Rightarrow$鞘糖脂
			2. 寡糖
		2. 最简单的糖脂：半乳糖脑苷脂
	4. 亲水头部、疏水尾部$\Rightarrow$两亲性分子 or 兼性分子==？？？==
	5. 膜脂分子“亲水又亲脂”特点致使其自组装
		1. 分子团：尾部向内的球形脂
		2. 脂双层：疏水的尾部被亲水的头部夹在中间
		3. 脂质体：较为稳定的自我封闭微囊结构
		![[Pasted image 20260309202206.png]]
2. 膜蛋白：
	1. 与脂双层的结合方式
		1. 膜整合蛋白/内在蛋白/跨膜蛋白（内侧/外侧，大部分/全部 插入脂双层，70-80%）
			1. 单次穿膜：以单条$\alpha$螺旋贯穿
			2. 多次穿膜：以多条$\alpha$螺旋贯穿
			3. $\beta$桶：卷起的$\beta$折叠形成桶样结构贯穿（多亚基跨膜）
			4. 通过肽链上两亲性$\alpha$螺旋锚定在脂双层的胞质单层
		2. 脂锚定蛋白/脂连接蛋白（共价键连接）
			1. 共价结合在胞质单层内的烃链或异戊烯基团上（细胞质侧）
				1. 氨基酸直接与N端的Gly（甘氨酸）残基结合锚定
				2. 烃链或脂肪酸直接与膜蛋白C端Cys（半胱氨酸）残基结合锚定
			2. 通过寡糖链共价结合在细胞膜非胞质面单层种的磷脂酰肌醇上（细胞外侧）
			![[Pasted image 20260309203139.png]]
		3. 膜周边蛋白/外在膜蛋白/周边蛋白（与信号分子结合）
			1. 通过非共价键结合在其他膜蛋白上
				1. 静电作用
				2. 离子键
				3. 氢键
			2. 水溶性蛋白
			3. 改变溶液的离子强度、温度、pH或加入金属螯合剂等可从膜上溶解下来
3. 膜糖
	1. 分类
		1. 糖蛋白
		2. 糖脂
	2. 细胞外被/糖蕚：
		1. 真核细胞表面富含糖类的外围区域
		2. 作用：
			1. 帮助抵御各种物理、化学或机械损伤
				```
				消化道、呼吸道等上皮细胞的细胞外被有助于润滑、防止机械损伤以及保护粘膜上皮不受消化酶作用
				```
			2. 细胞信息交流
			3. 细胞识别
				```
				红细胞ABO血型抗原
				```
			4. 细胞免疫
