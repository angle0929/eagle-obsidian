# 第二章 细胞膜的物质转运功能

> 本章地位：细胞基本功能的起点，也是理解**生物电（静息电位/动作电位）**和**肌肉收缩**的前提。
> 结构基础详见 [[细胞膜的分子结构和特性]]（[[医学细胞生物学]]）。

## 第一节 细胞膜的物质转运功能

### 一、细胞膜的化学组成与分子排列

**液态镶嵌模型**：液态**脂质双分子层**构成膜的基本构架，不同结构和功能的**蛋白质**镶嵌其中，**糖类**分子与脂质或蛋白结合后附在膜的**外表面**。

| 组成 | 要点 |
|---|---|
| **脂质** | 磷脂双分子层：亲水性极性基团（磷酸和碱基）朝向两侧，疏水性非极性基团（长烃链）相对向内；含胆固醇 |
| **蛋白质** | 承担转运、受体、催化等功能（见下"膜蛋白介导"） |
| **糖类** | 以**糖蛋白**或**糖脂**形式存在，分布于膜外表面 |

### 二、跨膜物质转运总览

```
跨膜物质转运
├─ 被动转运（顺梯度、不耗能）
│  ├─ 单纯扩散
│  └─ 易化扩散
│     ├─ 经通道的易化扩散
│     └─ 经载体的易化扩散
├─ 主动转运（逆梯度、耗能）
│  ├─ 原发性主动转运
│  └─ 继发性主动转运
└─ 膜泡运输（耗能）
   ├─ 出胞
   └─ 入胞
```

## （一）单纯扩散

- **定义**：脂溶性、小分子物质直接穿越脂质双层，顺浓度梯度（和/或电位梯度）的转运。
- **转运对象**：脂溶性小分子（如 O₂、CO₂、乙醇、类固醇激素等）。
- **影响因素**：① 膜两侧**浓度差**；② 膜的**通透性**。
- **特点**：不需膜蛋白、不消耗能量。

## （二）易化扩散

- **定义**：非脂溶性小分子物质或带电离子，在**跨膜蛋白**帮助下，顺浓度梯度和/或电位梯度进行的跨膜转运。
- 与单纯扩散的**共同点**：均为顺梯度、**不耗能**，属被动转运。

### 1. 经通道的易化扩散

- **定义**：各种**带电离子**在通道蛋白介导下，顺浓度梯度和/或电位梯度的跨膜转运。
- **转运物质**：Na⁺、K⁺、Ca²⁺、Cl⁻ 等。

**特点**：

1. **离子选择性**：每种通道只对一种或几种离子有较高通透能力，对其他离子通透性很小或不通透。
   - 例：钾通道对 K⁺ 的通透性比 Na⁺ 大 **1000 倍**。
2. **门控特性**：通道蛋白分子内有可移动结构或化学基团，在通道开口处起"**闸门**"作用，多种因素可引起闸门运动而改变通道开闭。

| 门控类型 | 调控因素 |
|---|---|
| **电压门控通道** | 膜两侧电位差（去极化） |
| **化学门控通道**（配体门控通道） | 膜外或膜内的化学物质 |
| **机械门控通道** | 机械外力（如膜膨胀/萎缩） |

### 2. 经载体的易化扩散

- **定义**：水溶性小分子物质在**载体蛋白**介导下，顺浓度差进行的跨膜转运。
- **转运对象**：小分子有机物，如**葡萄糖、氨基酸、核苷酸**等。
- **转运机制**："**底物结合 → 构象变化 → 底物解离**"，因需反复变构，**整体速度较慢**。

**特点**：

1. **结构特异性**：每种载体只能识别和结合具有特定化学结构的底物。
2. **饱和现象**：膜一侧物质浓度增加超过某一限度时，转运量不再随之增加。
   - **Vmax**：最大扩散速度；**Km**：达到 1/2 Vmax 时所需的底物浓度。
3. **竞争性抑制**：经同一载体转运的结构相似物质 A 与 B，环境中加入 B 会**减弱**载体对 A 的转运。

## （三）主动转运

- **定义**：某些物质在膜蛋白帮助下，由**细胞代谢提供能量**，进行的**逆**浓度梯度和/或电位梯度的跨膜转运。
- 分类：**原发性**主动转运、**继发性**主动转运。

### 1. 原发性主动转运（primary active transport）

- **定义**：**直接**利用细胞代谢产生的能量（ATP），逆浓度差和电位差进行的主动转运。
- **转运物质**：本质为**离子泵**。

| 离子泵 | 主要功能 |
|---|---|
| **钠-钾泵（钠泵，Na⁺-K⁺-ATP 酶）** | 每分解 1 分子 ATP，移出 **3 个 Na⁺**、移入 **2 个 K⁺**（最常见） |
| **钙泵**（Ca²⁺-ATP 酶） | 维持胞质**低钙** |
| **质子泵**（氢-钾泵） | **泌酸** |

**钠泵活动的生物学意义（重点）**：

1. 造成的细胞内**高 K⁺** 状态，是胞质内许多**代谢反应**所必需的。
2. **维持胞内渗透压和细胞容积**。
3. 形成的 Na⁺、K⁺ **跨膜浓度梯度**，是细胞发生电活动（**静息电位和动作电位**）的基础。
4. **生电效应**使膜内电位负值增大，**直接参与静息电位的形成**。
5. 建立的 Na⁺ 跨膜浓度梯度，为**继发性主动转运提供势能储备**。

### 2. 继发性主动转运（secondary active transport）

- **定义**：**间接**消耗能量——利用原发性主动转运（钠泵）所建立的离子浓度梯度作为驱动力，进行的逆浓度梯度转运。
- **典型实例**：葡萄糖、氨基酸在**小肠粘膜上皮细胞**和**肾小管上皮细胞**的吸收。
  - **管腔膜（顶膜）**：Na⁺ 与葡萄糖/氨基酸经同向转运体**一同入胞**（继发性主动转运）。
  - **基侧膜**：钠泵将 Na⁺ 泵出（原发性主动转运），葡萄糖经载体**易化扩散**入血。
  - 两层膜协同，构成完整的跨上皮转运。

## （四）膜泡运输

- **定义**：大分子和颗粒物质进出细胞时**不直接穿过细胞膜**，而是由膜包围形成**囊泡**，经膜包裹、融合和离断等一系列过程完成转运。

| 类型 | 英文 | 定义 | 备注 |
|---|---|---|---|
| **出胞** | exocytosis | 胞质内的大分子物质以**分泌囊泡**形式**排出**细胞 | 主要见于细胞的分泌活动、神经末梢递质释放 |
| **入胞** | endocytosis | 细胞外大分子物质或物质团块（如细菌、死亡细胞、细胞碎片）被膜包裹后以囊泡形式**进入**细胞，又称**内化** | 分**吞噬**（固体）与**吞饮**（液体） |

> 术语说明：出胞＝exocytosis，入胞＝endocytosis，符合规范定义（课件英文标注有误，此处按标准术语更正）。

## 三种转运方式综合对比

| 转运形式          | 转运对象       | 动力               | 是否耗能 | 关键特点               |
| ------------- | ---------- | ---------------- | ---- | ------------------ |
| **单纯扩散**      | 脂溶性、小分子    | 浓度差；顺梯度          | 否    | 取决于①浓度差 ②膜通透性      |
| **易化扩散（经通道）** | 离子         | 浓度差、电压差；顺梯度      | 否    | ①离子选择性 ②门控特性       |
| **易化扩散（经载体）** | 水溶性小分子、有机物 | 浓度差；顺梯度          | 否    | ①结构特异性 ②饱和性 ③竞争性抑制 |
| **原发性主动转运**   | 离子         | ATP；逆梯度          | 是    | 离子泵（钠泵/钙泵/质子泵）     |
| **继发性主动转运**   | 葡萄糖、氨基酸    | 间接耗能（离子梯度势能）；逆梯度 | 是    | 依赖钠泵建立的 Na⁺ 梯度     |
| **膜泡运输**      | 大分子物质或物质团块 | 耗能               | 是    | 分为出胞、入胞            |

## 考点提示

- **临床执业医师**：单纯扩散、易化扩散、主动转运、膜泡运输。
- **考研西医综合**：跨膜物质转运方式（含各类特点与判别）。

**易混点辨析**

- 经**通道** vs 经**载体**：通道转运**离子**、有**门控**、速度快；载体转运**小分子有机物**、有**饱和与竞争**、速度慢。
- **原发性** vs **继发性**主动转运：前者**直接**耗 ATP（泵本身水解 ATP）；后者**间接**耗能，依赖前者建立的离子梯度。
- 被动转运**一定**不耗能且顺梯度；主动转运**一定**逆梯度（二者判据为梯度方向，而非单纯看是否耗能）。
