# 第一章 绪论

> 本章地位：生理学的入门框架。核心考点为**内环境与稳态**、**三种调节方式**、**反馈/前馈控制系统**。

## 第一节 生理学的研究对象和任务

### 一、生理学的研究对象

- **生理学**（physiology）：生物科学的重要分支，研究机体生命活动中的各种现象及其**功能活动规律**的科学。
- **人体生理学**（human physiology）：研究人体功能活动及其规律的科学。
- 按研究对象可分为：病毒生理学、细菌生理学、植物生理学、动物生理学、人体生理学等。

**人体的九大系统**（形态基础见 [[系统解剖学]]）：

呼吸系统、消化系统、循环系统、内分泌系统、运动系统、生殖系统、感觉系统、神经系统、泌尿系统

### 二、生理学的研究任务

1. 阐明生命现象的**表现、规律与机制**
2. 阐明各种因素对功能的**影响及调节**
3. 揭示各项功能的**生理意义**

### 三、生理学与医学的关系

- 生理学是后续医学课程的**基础**，也是医务与卫生工作的理论基础。
- 经典论断：*医学是关于疾病的科学，生理学是关于生命的科学*，后者比前者**更有普遍性**。

### 四、生理学的认识层次

研究可在不同水平上进行，各层次相互联系：

| 层次 | 内容 |
|---|---|
| 细胞和分子层面 | 原子、分子（如 DNA）、细胞 |
| 器官和系统层面 | 组织、器官、系统 |
| 整体层面 | 机体整体及各系统的整合活动 |

对应 Levels of Biological Organization：Chemical level → Cellular level → Tissue level → Organ level → System level → Organismal level

## 第二节 生理学的常用研究方法

- 生理学是一门**实验性科学**，真正成为实验科学始于 17 世纪。

### 一、历史里程碑

1. **公元 2 世纪**：古罗马医士盖伦（Galen）提出"血液潮汐论"，认为血液流动以肝脏为中心——后被证实错误。
2. **1628 年**：英国医生**威廉·哈维**（William Harvey, 1578—1657）通过实验发现血液循环与心脏功能，出版《**心血运动论**》。
   - 该书推翻"血液潮汐论"，是**生理学诞生的标志**。
   - 恩格斯评价：哈维由于发现血液循环而把生理学确立为科学。

> 核心科学观：科学应以**实验**为依据，而不是以书本或前人的理论为依据。

### 二、实验分类

```
生理学实验
├─ 动物实验
│  ├─ 急性实验（在体实验 / 离体实验）
│  └─ 慢性实验
└─ 人体生理研究
```

## 第三节 生命活动的基本特征

| 基本特征 | 要点 |
|---|---|
| **新陈代谢** | 机体不断与周围环境进行物质和能量交换，以及机体内物质和能量的自我更新 |
| **兴奋性** | 机体的组织或细胞**接受刺激后发生反应**的能力 |
| **适应性** | 机体根据内外环境变化调整自身功能与结构的能力 |
| 生殖 | 自学 |
| 衰老 | 自学 |

- **兴奋**：可兴奋组织接受刺激产生反应时，表现为由相对静止变为明显的运动状态，或原有活动由弱变强的反应过程或反应形式。
- 兴奋性与兴奋的概念是后续 [[第二章 细胞膜的物质转运功能]]（生物电、动作电位）的基础。

## 第四节 机体的内环境、稳态和生物节律

### 一、体液及其分布（★执医、考研考点）

正常成年人体液约占**体重的 60%**：

```
体液（占体重 60%）
├─ 细胞内液 40%（占体液 2/3）
└─ 细胞外液 20%（占体液 1/3）
   ├─ 血浆（占细胞外液 1/4）
   └─ 组织液、淋巴液、脑脊液、房水等（占细胞外液 3/4）
```

### 二、内环境

- **内环境**（internal environment）：体内细胞生活的体液环境，即**细胞外液**。
- 内环境是细胞与外界环境进行物质交换的**媒介**（营养物质的摄入与代谢废物的排出均经此）。

### 三、内环境的稳态（★执医、考研考点）

- **稳态**（homeostasis）：内环境的**理化性质保持相对恒定**的状态。

| 理化指标 | 相对稳定值 |
|---|---|
| 温度 | 37 °C |
| 酸碱度 | pH 7.35—7.45 |
| 渗透压 | 300 mmol/L |
| 各种液体成分 | 相对稳定 |

> 相关基础：[[渗透压]]、[[酸与碱]]、[[水]]（见 [[医用化学]]）

- **意义**：稳态是机体进行正常生命活动的**必要条件**。
- **狭义**稳态：指内环境理化性质的相对恒定。
- **广义**稳态：泛指从分子、细胞水平到器官、系统水平和整体水平的各种生理活动，在神经和体液等因素调节下保持相对稳定的状态。

## 第五节 机体生理功能的调节（★执医、考研考点）

三种基本调节方式对比：

| 调节方式 | 基本方式/途径 | 特点 |
|---|---|---|
| **神经调节**<br>neural regulation | 反射；结构基础为**反射弧** | 反应迅速、历时短暂、作用准确而局限<br>（**快、准、短**） |
| **体液调节**<br>humoral regulation | 特殊化学物质经体液运输作用于靶细胞受体 | 作用缓慢、历时持久、范围大而精确度差<br>（**慢、广、久**） |
| **自身调节**<br>autoregulation | 组织细胞凭借内在特性对局部变化产生适应性反应 | 强度较弱、范围较小、灵敏度较低 |

### 一、神经调节

- **反射弧**组成：感受器 → 传入神经 → 中枢 → 传出神经 → 效应器。
- **反射的类型**：
  - **非条件反射**：先天、固定，维持本能活动。
  - **条件反射**：后天、可变，增强适应能力。
- 神经调节是**最主要、最快速准确**的调节方式。

### 二、体液调节

- 分泌方式：
  - **远距离分泌**（telecrine）：经血液循环运至远处靶细胞。
  - **旁分泌**（paracrine）：作用于邻近细胞。
  - **自分泌**（autocrine）：作用于分泌细胞自身。
  - **神经分泌**（neurocrine）：神经末梢释放化学物质。

### 三、自身调节

- 不依赖神经调节和体液调节，由组织器官本身内在特性决定，调节范围局限。

## 第六节 人体内自动控制系统（★执医、考研考点）

```
人体内在控制系统
├─ 非自动控制系统
├─ 反馈控制系统
│  ├─ 负反馈（negative feedback）
│  └─ 正反馈（positive feedback）
└─ 前馈控制系统（feed-forward）
```

- **反馈**：由受控部分发出的信息反过来影响控制部分的活动。

### 一、负反馈

- **定义**：反馈信息的作用与控制信息的作用**相反**，使控制信息的效应减弱或抑制。
- **意义**：**维持稳态**。
- **举例**：动脉血压的压力感受性反射（减压反射）等。
- **缺点**：**滞后**、**波动**（因须待偏差出现后才纠正）。

### 二、正反馈

- **定义**：反馈信息**促进与加强**控制部分的活动，使受控部分活动朝着与原先变化相同的方向改变。
- **意义**：促进某些生理过程**快速完成**。
- **举例**：排尿反射、分娩过程、**血液凝固**过程、**动作电位上升支**（Na⁺ 内流）。
- **与稳态的关系**：破坏局部稳态，维持整体稳态。

### 三、前馈

- **定义**：在反馈信息尚未到达前，控制部分已受纠正信息（前馈信息）影响，**提前**纠正其指令可能出现的偏差。
- **优点**：富有**预见性**（如寒冷时体温下降前的预先调节）。
- **缺点**：可能**失误**。

## 本章小结

**重点**
- 内环境和稳态的概念
- 生理功能的调节方式及其特点
- 人体自动控制系统

**难点**
- 神经调节、体液调节和自身调节的特点
- 反馈控制系统（负反馈与正反馈的判别）

## 考点对照

- **临床执业医师**：体液及其分布；内环境及其稳态；神经调节、体液调节和自身调节；反馈（负反馈和正反馈）；前馈。
- **考研西医综合**：体液、内环境与稳态；三种调节方式；负反馈、正反馈、前馈调节。

## 自测

1. 阐述内环境稳态的概念及其生理意义。
2. 举例说明什么是负反馈调节，它有何生理意义？
3. **不属于机体内环境的是**：A 房水 / B 淋巴液 / C 脑脊液 / **D 细胞内液** / E 血浆 → 答案 **D**（内环境＝细胞外液）
4. **负反馈调节参与的是**：**A 呼吸性酸中毒时呼吸加快加深** / B 动作电位去极化 / C 止血过程 / D 体温昼夜节律 / E 排尿时膀胱收缩 → 答案 **A**（B、C、E 属正反馈）
