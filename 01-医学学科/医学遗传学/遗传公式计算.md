# 符号说明

| 符号 | 含义 |
|:---|:---|
| $p$ | 显性等位基因频率 |
| $q$ | 隐性等位基因频率 |
| $p + q = 1$ | 哈迪-温伯格平衡 |
| $q^2$ | 常染色体隐性纯合子频率 |
| $2pq$ | 常染色体显性杂合子频率 |
| $q$ | X连锁隐性男性患病率（半合子） |
| $p$ | X连锁显性男性患病率（半合子） |

# 四大遗传方式

| 遗传方式             | 基因型                               | 男性患病率                          | 女性患病率                          | 男女比例                                   |
| :--------------- | :-------------------------------- | :----------------------------- | :----------------------------- | :------------------------------------- |
| **AR**<br>常染色体隐性 | $aa$                              | $q^2$                          | $q^2$                          | $1:1$                                  |
| **AD**<br>常染色体显性 | $Aa + AA$                         | $2pq + p^2$<br>≈ $2p$（当$p$很小时） | $2pq + p^2$<br>≈ $2p$（当$p$很小时） | $1:1$                                  |
| **XR**<br>X连锁隐性  | $X^aY$（男）<br>$X^aX^a$（女）          | $q$                            | $q^2$                          | $\frac{1}{q}:1$<br>（男多于女）              |
| **XD**<br>X连锁显性  | $X^AY$（男）<br>$X^AX^A + X^AX^a$（女） | $p$                            | $p^2 + 2pq$<br>≈ $2p$（当$p$很小时） | $1:\frac{2}{1+q}$<br>≈ $1:2$<br>（女多于男） |

# 携带者频率速算

| 遗传方式 | 携带者定义 | 携带者频率 | 备注 |
|:---|:---|:---|:---|
| **AR** | $Aa$ | $2pq$ ≈ $2\sqrt{\text{患病率}}$ | 当患病率很低时，$q$很小，$p≈1$ |
| **XR** | $X^AX^a$（女性） | $2pq$ ≈ $2q$ | 女性携带者频率≈2倍男性患病率 |
| **AD** | 通常不称携带者 | — | 杂合子即患病 |
| **XD** | 通常不称携带者 | — | 杂合子即患病 |

# 适用速算公式

> [!tip] AR遗传病速算
> - 患病率 = $q^2$
> - 基因频率 $q = \sqrt{\text{患病率}}$
> - 携带者频率 = $2q$（当患病率<1/10000时，误差<1%）

> [!tip] XR遗传病速算
> - 男性患病率 = $q$（直接等于基因频率）
> - 女性患病率 = $q^2$（男性患病率的平方）
> - 女性携带者频率 = $2q$（≈ 2 × 男性患病率）
> - **关键比例**：男患者 : 女患者 : 女携带者 = $q : q^2 : 2q$ = $1 : q : 2$

> [!tip] XD遗传病速算
> - 男性患病率 = $p$（直接等于基因频率）
> - 女性患病率 ≈ $2p$（当$p$很小时，纯合子$AA$可忽略）
> - **关键比例**：女患者 ≈ 2 × 男患者

# 近亲婚配（涉及亲缘系数）

| 亲缘关系 | 亲缘系数 $r$ | AR风险加成 | XR风险加成（姨表/舅表） |
|:---|:---|:---|:---|
| 随机婚配 | 0 | 基准 | 基准 |
| 表兄妹 | $1/8$ | × $(1+16F)$ | 姨表：$F=3/16$<br>舅表：$F=2/16$ |
| 半同胞 | $1/4$ | × $(1+8F)$ | 视具体情况 |
| 全同胞/亲子 | $1/2$ | × $(1+4F)$ | 极高风险 |
> [!warning] XR遗传病特殊规则
> 姨表兄妹婚配风险（$F=3/16$）> 舅表兄妹（$F=2/16$）> 姑表/堂兄妹（$F=0$）

姨表兄妹 vs 舅表兄妹对比（补充）

| 对比维度        | 姨表兄妹           | 舅表兄妹             |
| :---------- | :------------- | :--------------- |
| **定义**      | 母亲的姐妹（姨妈）的子女   | 母亲的兄弟（舅舅）的子女     |
| **血缘远近**    | r = 1/8        | r = 1/8          |
| **共同祖先**    | 外祖父母           | 外祖父母             |
| **X染色体传递**  | 外祖母→母亲/姨妈（女性链） | 外祖母→母亲；外祖母→舅舅→女儿 |
| **X染色体同源性** | 高（两位母亲共享外祖母X）  | 低（舅舅X不传儿子）       |
| **XR遗传病风险** | **高（F=3/16）**  | 中等（F=2/16）       |
| **AR遗传病风险** | F=1/16         | F=1/16           |

# 完整公式汇总

| 遗传方式 |   男患病率    |   女患病率    |   携带者    |
| :--: | :-------: | :-------: | :------: |
|  AR  |   $q^2$   |   $q^2$   |  $2pq$   |
|  AD  | $2pq+p^2$ | $2pq+p^2$ |    —     |
|  XR  |    $q$    |   $q^2$   | $2pq$（女） |
|  XD  |    $p$    | $p^2+2pq$ |    —     |

>[!warning] 携带致病基因概率问题
>对于AR病，已知群体发病率为$\frac{1}{10000}$，求群体中携带致病基因的概率（即$2pq$）
>$q^2 = \frac{1}{10000},则q= \frac{1}{100}$
>携带致病基因的概率为$2pq$
>$\because q \rightarrow 0,则p \rightarrow 1$
>$\therefore 2pq \approx 2q = \frac{1}{50}$
>同理，用此思维可以计算出其他遗传方式携带致病基因问题
