# 渗透现象

1. 半透膜：只允许某些物质（小分子、离子）通过，不允许另一些物质通过的薄膜
2. 渗透：溶剂分子透过半透膜进入溶液的扩散现象
3. 产生条件
	1. 有半透膜
	2. 半透膜两侧有浓度差
4. 渗透平衡：e.g.单位时间内，水分子进出半透膜的速率相等时，也液面停止上升

# #渗透压

1. 定义：恰好能阻止渗透现象发生，达到动态平衡的压强
	1. 单位：$Pa/kPa$
	2. 符号：$\Pi$
2. 与温度、浓度的关系
	1. 溶液在一些情况下，同样适用理想气体方程：$PV=nRT$
	2. $c_B=\frac{n_B}{v} \Rightarrow \Pi=ic_BRT$（e.g.溶质为$NaCl$时，$i=2$）==电解质？强？弱？==
		- $c_B单位为mol/L时，\Pi的单位为kPa$
		-  $c_B单位为mol/m^3或mmol/L时，\Pi的单位为Pa$→$1mol=10^{3}mmol$
		- T是开尔文温度，$T=273.5+t(摄氏温标)$
		- $R=8.314Pa \cdot  m^3 \cdot K^- mol^-$
	3. $c_B= \frac{n_B}{V}= \frac{m_B}{M_B \cdot V} \Rightarrow M_B= \frac{m_BRT}{\Pi V}$ ==计算大分子的相对分子质量==
3. 渗透浓度（ #物质的量的浓度 ）
	1. 定义：在溶液中能产生渗透效应的***各种溶质的分子和离子的总浓度***
		1. 单位：$mol/L,mmol/L$
		2. 符号：$c_{os}$
		3. 公式：$c_{os}= \frac{n_B}{V}= \frac{ρ_B}{M_B}$（==此处的单位为mol/L,要注意转换）
	2. ==电解质？强？弱？==
		1. 非电解质：$c_{os}=c_B$
		2. 强电解质：渗透浓度等于溶液中离子的总浓度
	3. 等渗、低渗、高渗溶液(==注意单位为mmol/L==)
		1. 等渗溶液：$c_{os} \in (280mmol/L,320mmol/L)$
			1. 血浆：$c_{os}≈303.7mmol/L$
			2. 生理盐水（$NaCl溶液$）:$ρ_B=9g/L$
			3. 等渗葡萄糖溶液：$ρ_B=50g/L$
			4. 等渗乳酸溶液：$ρ_B=19g/L$
			5. 等渗$NaHCO_3溶液$：$ρ_B=12.5g/L$
				==除以摩尔质量即可转换为渗透浓度==
		2. 低渗溶液：$c_{os}<280mmol/L$
			溶血：使红细胞吸水膨胀至破裂（此处的低渗指的是细胞外液，高渗溶液中的内容同理）
		3. 高渗溶液 ：$c_{os}>320mmol/L$
			胞浆分离：使红细胞逐渐失水皱缩
4. 晶体渗透压和胶体渗透压

|           | 晶体渗透压                        | 胶体渗透压                  |
| --------- | ---------------------------- | ---------------------- |
| 物质        | 小分子物质<br>e.g.无机盐             | 大分子物质<br>e.g.蛋白质       |
| 渗透压/$kPa$ | 766                          | 4                      |
| 功能        | 调节细胞内外液中水和盐的相对平衡<br>决定水的渗透方向 | 调节毛细血管内外水和盐的相对平衡，维持血容量 |
	1. 口渴：脑部有大量的神经，感觉灵敏；缺水的时候，细胞外液的晶体渗透压上升，大于细胞内液渗透压，导致细胞失水
	2. 水中毒：大量补水或者葡萄糖溶液时，细胞外液渗透压降低，小于细胞内液渗透压，导致细胞吸水膨胀甚至涨破
	3. 水肿：某种原因导致毛细血管内的蛋白质减少，使胶体渗透压下降，导致过量小分子（e.g.水分子）进入组织间液
