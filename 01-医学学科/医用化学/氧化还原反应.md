#医用化学

# 氧化值

1. 定义：某元素一个原子的荷电数，该荷电数是假定把每一个化学键中的成键电子指定给==电负性较大==的原子而求得
	有点类似于化合价，但是化合价只能是整数，而氧化值是有理数
	$Fe_3O_4中用平均化合价法计算出来的 \frac{8}{3} 实际上是氧化值$
2. 几个基本规则
	1. 单质中原子的氧化值为0
	2. H在化合物中的氧化值一般是1；但在活泼金属氢化物中为-1
	3. 氧在化合物中的氧化值一般为-2；但是在过氧化物中氧化值为$-\frac{1}{2}$；在$OF_2$中氧化值为+2
	4. 卤素元素的氧化值也有多种情况
		1. $NaCl中为-1$
		2. $BrCl中Br为+1，Cl为-1$
		3. $ClO_2中为+4$
	5. 单原子离子，元素的氧化值等于该元素离子的电荷数
	6. 电中性化合物中，所有元素原子的氧化值的代数和等于0

# 氧化-还原反应

|         | 氧化剂  | 还原剂  |
| ------- | ---- | ---- |
| 得失电子    | 失    | 得    |
| 化合价/氧化值 | 升高   | 降低   |
| 产物      | 还原产物 | 氧化产物 |

## 氧化-还原半反应

氧化型+$ne^-$=还原型
$Ox+ne^-=Red$

## 氧化-还原反应半反应何氧化还原电对

1. 氧化还原电对：每个半反应中都包含同一元素的两种不同氧化态，将氧化值高的叫做氧化性（Ox），氧化值低的叫做还原性（Red）
2. 它们互为共轭关系
	氧化态/还原态
	e.g. $Cu^{2+}/Cu和Zn^{2+}/Zn$
3. 物质的氧化型（Cu）的氧化性越强，与其共轭的还原型物质的还原性就越弱
