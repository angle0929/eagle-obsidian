# 生物化学

重庆医科大学《生物化学》课程笔记，授课教师：李轶副教授（生物化学与分子生物学教研室）。
内容依据课堂课件提炼并重组整合，仅保留知识要点与考点，不收录考核办法等行政信息。
教材框架共五篇：生物大分子结构与功能 → 物质代谢及调控 → 遗传信息传递及调控 → 生化专题 → 分子生物学专题（第二学期）。

## 学习主线（进化式回顾）

```
绪论（学科坐标）
  └─ 蛋白质：组成（原材料）→ 结构（组装层级）→ 功能（结构决定功能）
      ├─ 反例一：序列坏 → 分子病（镰刀状贫血）
      ├─ 反例二：形状坏 → 构象病（疯牛病）
      └─ 性质应用（电学/胶体/变性/显色 → 实验室与临床）
  └─ 下一章：核酸的结构与功能（结构-功能主线平移到 DNA/RNA）
```

## 关联学科（知识图谱）

- [[医用化学]]：
  - [[酸与碱]] — 氨基酸与蛋白质两性解离、等电点的酸碱理论根基（弱电解质解离、pH、缓冲液）
  - [[渗透压]] — 血浆蛋白的胶体性质对应**胶体渗透压**，维持血管内外水平衡
- [[医学遗传学]] — 镰刀状红细胞贫血的点突变（GAG→GTG）与遗传方式判别见 [[遗传公式计算]]；发展简史中的孟德尔遗传定律
- [[生理学]] — [[第二章 细胞膜的物质转运功能]] 中执行转运的载体、通道、钠泵**都是蛋白质**（本篇"结构与功能"是其分子基础）；血氧饱和度指标贯穿内环境与呼吸章节
- [[医学细胞生物学]] — 细胞学说（绪论背景）；[[细胞膜的分子结构和特性]] 中的膜蛋白构象与功能
