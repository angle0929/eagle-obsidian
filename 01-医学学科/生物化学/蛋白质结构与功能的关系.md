# 蛋白质结构与功能的关系

> 本章地位：全章的灵魂——用 7 个例子回答"结构如何决定功能、结构坏了会怎样"。老师强调：**记 point + 例子**，生化里的例子考试必考。
> 结构本身见 [[蛋白质的分子结构]]；理化性质的应用见 [[蛋白质的理化性质]]。

## 〇、总纲（辩证关系）

```
一级结构 ──决定──> 空间构象 ──决定──> 生物学功能
   ↑                    ↑
（可被基因改变）      （可被折叠错误/别构剂改变）
```

蛋白质的主要功能：防御、结构、储存、催化、信号传递、运输等——**功能以结构为基础**。

## 一、一级结构与功能的关系（3 个 point + 对应例子）

### Point 1：一级结构是空间构象的基础

- **例子：牛核糖核酸酶的变性与复性**（一级结构 = 氨基酸残基排列顺序 + 二硫键位置）：
  - 用 **8M 尿素 + β-巯基乙醇**破坏非共价键与二硫键 → 酶变性失活（一级结构/肽键未破坏）；
  - **去除尿素和 β-巯基乙醇**后 → 空间构象恢复，功能恢复。
- 结论：只要一级结构（肽键）未被破坏，空间构象可重建、功能可恢复。（延伸：变性/复性的理化细节见 [[蛋白质的理化性质]]。）

### Point 2：一级结构相似的蛋白质具有相似的高级结构与功能

- **例子：不同哺乳动物的胰岛素**——均由 A、B 两个亚基组成（A 链 21、B 链 30 个残基），仅个别残基有差异：

| 物种 | A5 | A6 | A10 | B30 |
|---|---|---|---|---|
| 人 | Thr | Ser | Ile | Thr |
| 猪 | Thr | Ser | Ile | Ala |
| 狗 | Thr | Ser | Ile | Ala |
| 兔 | Thr | Gly | Ile | Ser |
| 牛 | Ala | Gly | Val | Ala |
| 羊 | Ala | Ser | Val | Ala |
| 马 | Thr | Ser | Ile | Ala |

- 种属间高度保守（多数位点相同）→ 功能相同（降血糖）；猪胰岛素与人仅 B30 一个残基之差（临床上曾用作替代治疗）。

### Point 3：一级结构中关键部位氨基酸残基的改变引起功能异常

**例 a：胰岛素残基去除实验（"关键部位"的含义）**

| 去除残基位置 | 胰岛素活性变化 |
|---|---|
| A 链羧基端 Asn | **失活** |
| B 链羧基端 Ala | 无影响 |
| B 链 23-30 氨基酸残基 | 活性显著下降（15%） |

→ 说明并非所有残基都同等重要，"关键部位"的改动才致功能异常。

**例 b：镰刀状红细胞贫血（分子病经典）**

| | 红细胞形态 | 血红蛋白 | α 亚基 | β 亚基 | 去氧血红蛋白溶解度 |
|---|---|---|---|---|---|
| 正常 | 圆形/椭圆 | HbA | 2 个 | 2 个 | 正常 |
| 患者 | **镰刀状** | HbS | 2 个 | 2 个，**第 6 位氨基酸突变** | 降低 |

**机制链（完整因果，须会复述）**：
1. 基因层面：密码子 **GAG → GTG**（点突变）；
2. 蛋白层面：HbS 的 **β 亚基第 6 位 Glu（酸性氨基酸）→ Val（非极性疏水氨基酸）**；
3.分子层面：pH 7.4 时 Val 使 HbS 分子表面形成一个**疏水突起**，与另一 HbS分子 β 亚基上的**疏水口袋**（Phe85、Leu88）互补，经**疏水作用力**相互结合；
4. 细胞层面：HbS 分子间沉积聚合为纤维状结构，压迫红细胞膜使其弯曲呈**镰刀状**；细胞平滑性与弹性下降，不易通过毛细血管。

- **分子病**：由于**基因结构改变**，引起蛋白质一级结构中的**关键氨基酸**发生改变，导致蛋白质功能障碍、出现相应临床症状的疾病。
- 遗传层面延伸：该病属常染色体隐性遗传，判别方法见 [[遗传公式计算]]（[[医学遗传学]]）。

## 二、空间构象与功能的关系：血红蛋白与肌红蛋白

### 1. Hb 与 Mb 结构对比（结构相似、功能机制不同）

| | 肌红蛋白 Mb | 血红蛋白 Hb |
|---|---|---|
| 分子组成 | **单链**蛋白质（154 个残基） | **四聚体**（α₂β₂） |
| 二级结构特点 | **8 段 α-螺旋** | 各亚基三级结构与 Mb 极为相似 |
| 血红素辅基 | **1 个** | **4 个** |
| 额外稳定因素 | — | **8 个离子键**（脱氧态，连接亚基间） |
| 氧合方式 | 直接与 O₂ 可逆结合 | 4 亚基**依次**与 O₂ 结合（有协同） |
| 附加功能 | — | 还能运输 **H⁺ 和 CO₂** |
| 生理定位 | 储氧（推断：教材通识，课件正文强调可逆氧合与结构对比） | 运氧 |

### 2. 氧饱和曲线：协同效应与别构效应（名解 + 曲线辨析，本章最核心考点）

**数据感受（PO₂ 与氧饱和度 %）**：

| PO₂ (mmHg) | Mb 饱和度 (%) | Hb 饱和度 (%) |
|---|---|---|
| 0 | 0 | 0 |
| 20 | 80 | 20 |
| 40 | 95 | 60 |
| 60 | 100 | 80 |
| 80 | 100 | 90 |
| 100 | 100 | 95 |

- **曲线形状（必记）**：**Mb 呈直角双曲线**（单亚基、无协同）；**Hb 呈 S 型曲线**（多亚基、有协同）。
- **协同效应**：一个亚基与**配体**（O₂）结合后，能影响（促进/抑制）**另一亚基**与配体结合的现象。Hb 中：第一个亚基结合 O₂ 后促进第二、三亚基结合，第三亚基结合后促进第四个亚基结合。
- **别构效应（又称变构效应）**：氧分子与 Hb **一个亚基**结合后，引起**亚基构象变化**的现象。O₂ 是**别构剂（效应物）**，Hb 是**别构蛋白**。
- **分子机制（T 态 → R 态）**：O₂ 与 **Fe²⁺** 配位 → Fe²⁺ 向卟啉环小孔移动 → 引起肽段移动 → 两个 α 亚基间**离子键断裂** → 亚基结合松弛（T 态紧张 → R 态松弛）→ 利于下一亚基结合 O₂ → 四个亚基全部进入 **R 态（松弛态）**。
- **两个效应的关系（辨析）**：
  - **别构效应 = 蛋白质结构（构象）变化**（分子机制层面）；
  - **协同效应 = 表观功能参数变化**（亚基间结合能力互相影响的表现）；
  - 别构效应是协同效应的**结构基础**：构象改变（别构） → 亚基间亲和力互相影响（协同）。
- 后续呼应：代谢调节中的**别构酶**（第二篇物质代谢）用的正是同一原理。

## 三、空间构象改变可致病：蛋白质构象疾病（考名解）

- **蛋白质构象疾病**：若蛋白质的**折叠发生错误**，尽管其**一级结构不变**，但**构象改变**仍可影响功能，严重时可导致疾病。
- **机理**：错误折叠的蛋白质相互聚集，常形成**抗蛋白水解酶的淀粉样纤维沉淀**，产生毒性而致病（蛋白质淀粉样纤维沉淀的病理改变）。
- 包括：人纹状体脊髓变性病、老年痴呆症、亨廷顿舞蹈病、疯牛病等。

**必记例子：疯牛病与朊病毒蛋白 (prion protein, PrP)**

| | PrPc（正常） | PrPsc（致病） |
|---|---|---|
| 构象 | 富含 **α-螺旋** | 转变为**全为 β-折叠** |
| 理化性质 | 可溶、可被消化清除 | **水溶性差、热稳定** |
| 归宿 | 正常代谢 | 不被消化、不被免疫系统识别清除 → 沉积于大脑形成**淀粉样纤维沉淀**而致病 |

- 传播由 PrP 组成的传染颗粒完成，是一组人与动物的神经退行性病变。

## 四、本章总对比：分子病 vs 构象病（进化式整合，一表收束）

| | 分子病 | 蛋白质构象疾病 |
|---|---|---|
| 变化层面 | **一级结构**（关键氨基酸改变） | **空间构象**（一级结构不变） |
| 根源 | 基因结构改变（点突变） | 蛋白质折叠错误 |
| 病理物质基础 | 突变蛋白功能异常（如 HbS 聚合） | 抗蛋白酶的**淀粉样纤维沉淀** |
| 代表疾病 | 镰刀状红细胞贫血 | 疯牛病（PrPc→PrPsc）、老年痴呆、亨廷顿舞蹈病 |
| 记忆抓手 | **序列坏了** | **形状坏了** |

## 考点提示

- **名解**：分子病、蛋白质构象疾病、协同效应、别构效应。
- **例子题（必考）**：镰刀状贫血因果链（GAG→GTG；β6 Glu→Val；疏水突起-疏水口袋-纤维聚合）；疯牛病 PrPc（α 螺旋）→PrPsc（β 折叠）。
- **曲线题**：Mb 直角双曲线 vs Hb S 型曲线；对应结构基础（单亚基 vs 四聚体协同）。
- **辨析题**：协同效应（表现型）vs 别构效应（机制型）；T 态/R 态转换中离子键的断裂。
- 理解性掌握：牛核糖核酸酶复性实验支持"一级结构决定空间构象"这一论断。
