# 蛋白质的分子组成

> 本章地位：蛋白质全章的"原材料"层——先弄清元素与氨基酸，再由氨基酸组装出肽与蛋白质。
> 结构组装详见 [[蛋白质的分子结构]]；功能层面详见 [[蛋白质结构与功能的关系]]。

## 一、元素组成与定量（计算题）

- 蛋白质(protein)是由**氨基酸**(amino acids)通过**肽键**(peptide bond)相连形成的高分子**含氮化合物**。
- 主要元素：**C、H、O、N、S**。
- **含氮量很接近，平均 16%**——这是凯氏定氮法的理论依据。

**凯氏定氮法**：只要测定生物样品中的含氮量，即可推算蛋白质大致含量。

$$样品中蛋白质的含量(g) = 样品含氮量 \div 16\%$$

> 例题：100g 牛肉中氮含量是 3.2g，蛋白质含量 = 3.2 ÷ 16% = **20g**。
> 口径提示：体内含氮物质以蛋白质为主，故测总氮可近似代表蛋白含量（推断：这是方法近似性的来源）。

## 二、氨基酸：蛋白质的基本组成单位

### 1. 结构通式与构型

- 通式：与 **α-碳原子（Cα）** 相连的四个基团——氨基、羧基、氢、**R 侧链**（R 决定氨基酸的种类与性质）。
- 存在于自然界的氨基酸有 300 余种，但**组成人体蛋白质的常见氨基酸仅有 20 种**。
- 除**甘氨酸**（R = H，无手性碳）和**脯氨酸**（亚氨基酸，环状）外，均属 **L-α-氨基酸**。
- ⚠️ 老师要求：**要记氨基酸的三字符号**（下表已含三字与一字符号）。

### 2. 分类一：按 R 侧链的极性与酸碱性（四类，核心分类）

| 类别 | 氨基酸（中文名 / 三字 / pI） | 侧链特征 |
|---|---|---|
| **非极性疏水性**（7 种） | 甘氨酸 Gly 5.97、丙氨酸 Ala 6.00、缬氨酸 Val 5.96、亮氨酸 Leu 5.98、异亮氨酸 Ile 6.02、脯氨酸 Pro 6.30、苯丙氨酸 Phe 5.48 | 侧链仅含 C、H（R = 烃链），水中溶解度小 |
| **极性中性**（8 种） | 丝氨酸 Ser 5.68、半胱氨酸 Cys 5.07、蛋氨酸 Met 5.74、天冬酰胺 Asn 5.41、谷氨酰胺 Gln 5.65、苏氨酸 Thr 5.60、色氨酸 Trp 5.89、酪氨酸 Tyr 5.66 | R = 有极性但不带电荷的基团，易溶于水 |
| **酸性**（2 种） | 天冬氨酸 Asp 2.97、谷氨酸 Glu 3.22 | R = 负性解离基团，生理条件下带**负**电荷，pI 显著低 |
| **碱性**（3 种） | 赖氨酸 Lys 9.74、精氨酸 Arg 10.76、组氨酸 His 7.59 | R = 正性解离基团，生理条件下带**正**电荷，pI 显著高 |

> 注：中性氨基酸共 15 种（非极性 7 + 极性中性 8）；蛋氨酸（甲硫氨酸）按侧链归入极性中性类（课件口径）。
> 课件笔记"看 B 站课程完善分类"——上表已按教材口径补全，可直接复习。

### 3. 分类二：按营养必需性（8 + 12）

- **营养必需氨基酸（8 种，体内不能合成、必须由食物供给）**：Ile、Leu、Trp、Lys、Thr、Met、Val、Phe。
  - 记忆口诀（辅助）：**"甲（Met）携（Val）来（Lys）一（Ile）本（Phe）亮（Leu）色（Trp）书（Thr）"**。
- **营养非必需氨基酸（12 种）**：其余。

### 4. pI 规律速记

- 酸性氨基酸 pI 最低（约 2.9~3.2）——两个羧基，易解离出 H⁺。
- 碱性氨基酸 pI 最高（7.59~10.76）——侧链含可解离的碱性基团。
- 中性氨基酸 pI 都在 6 附近（5.07~6.30）——α-羧基与 α-氨基解离能力相近。

## 三、氨基酸的理化性质（三条，每条对应一种应用）

### 1. 两性解离与等电点（考名解 + 选择）

- 氨基酸是**两性电解质**：氨基可结合 H⁺，羧基可解离出 H⁺；解离程度取决于溶液 pH。
- **等电点(isoelectric point, pI)**：在某一 pH 的溶液中，氨基酸解离成阳离子和阴离子的**趋势及程度相等**，成为**兼性离子，呈电中性**，此时溶液的 pH 称为该氨基酸的等电点。

```
pH < pI：R-CH(NH3+)-COOH   阳离子   ← 加 OH⁻ →
pH = pI：R-CH(NH3+)-COO⁻   兼性离子（净电荷 = 0）
pH > pI：R-CH(NH2)-COO⁻    阴离子   ← 加 H⁺ →
```

- 蛋白质同样具有两性解离与等电点（见 [[蛋白质的理化性质]]）；问 pI 时主语可表述为"**蛋白质和氨基酸等两性电解质**"。

### 2. 茚三酮显色反应

- 氨基酸与**茚三酮**水合物在**弱酸性**溶液中共热 → **蓝紫色化合物**，最大吸收峰 **570nm**。
- 用途：氨基酸定性/定量分析（对象：游离氨基酸；蛋白质水解后产生的氨基酸也可反应）。

### 3. 紫外吸收性质（选择性吸收，记忆顺序）

- 含**共轭双键**的**芳香族氨基酸**在紫外光区有最大吸收峰。
- **吸光度顺序（必背）**：色氨酸 Trp 280nm > 酪氨酸 Tyr 275nm > 苯丙氨酸 Phe 257nm > 二硫键 240nm > 肽键 215nm。
- 大多数蛋白质含 Trp、Tyr 残基 → 测 **280nm** 吸光值即可快速简便定量蛋白（延伸见 [[蛋白质的理化性质]]）。

## 四、肽：从氨基酸到肽链

### 1. 肽键与氨基酸残基

| 概念 | 定义 |
|---|---|
| **肽键** | 一个氨基酸的 **α-羧基**与另一个氨基酸的 **α-氨基脱水缩合**形成的化学键 |
| **氨基酸残基**(residue) | 肽链中因脱水缩合而**基团不全**的氨基酸分子 |
| **肽**(peptide) | 氨基酸通过肽键缩合形成的**线性聚合物**，也称肽链 |

- **方向性（易错）**：肽链的书写与阅读方向为 **N 端（氨基末端）→ C 端（羧基末端）**。
  - 例：①Ala-Arg-Ser-Gly-His 与 ②His-Gly-Ser-Arg-Ala 是**不同**的肽——顺序相同但方向相反即不同。
- 命名：寡肽(oligopeptide)——氨基酸残基数较少（10 个以内）；多肽(polypeptide)——残基数 10 个以上（教材通识口径，课件表格表述不完整，此处以教材为准）。

### 2. 生物活性肽：谷胱甘肽（GSH，重点例子）

> 老师强调："生化里面提到的例子都很重要，一定要记。"

| 要点 | 内容 |
|---|---|
| 组成 | **谷氨酸 + 半胱氨酸 + 甘氨酸**（三肽） |
| 关键基团 | 半胱氨酸的**巯基(-SH)**——主要功能基团，具**还原性**与嗜核特性 |
| 核心反应 | 2GSH（还原型）⇌ GSSG（氧化型） |
| 抗氧化机制 | 2GSH + H₂O₂ →（**GPx，谷胱甘肽过氧化物酶**）→ GSSG + 2H₂O；GSSG 再由 NADPH 还原回 GSH |
| 其他活性肽 | 多肽类激素（催产素、加压素、促肾上腺皮质激素）、神经肽（脑啡肽、β-内啡肽、强啡肽、P 物质）、抗菌多肽等 |

## 五、整章逻辑图（进化式小结）

```
元素 C H O N S（含氮 16% → 凯氏定氮）
  └─ 20 种 L-α-氨基酸（除 Gly / Pro）
      ├─ 分类：非极性 7 ｜ 极性中性 8 ｜ 酸性 2 ｜ 碱性 3
      ├─ 理化：两性解离(pI) ｜ 茚三酮(570nm) ｜ 紫外(280nm)
      └─ 脱水缩合 → 肽键 → 肽（N→C 方向）
          ├─ 生物活性肽：GSH（谷-半胱-甘，巯基抗氧化）
          └─ 多肽链 → 见 [[蛋白质的分子结构]]（一~四级结构）
```

## 考点提示

- **计算题**：凯氏定氮法（÷16%）。
- **名解**：等电点(pI)、肽键、氨基酸残基。
- **选择**：20 种氨基酸的四分类归属（尤其 Asp/Glu 唯二酸性、Lys/Arg/His 唯三碱性）；必需氨基酸 8 种；甘氨酸/脯氨酸是 L-α-氨基酸的两个例外。
- **选择**：紫外吸收顺序 Trp 280 > Tyr 275 > Phe 257；茚三酮反应产物与波长（570nm）。
- **例子题**：GSH 的组成（谷-半胱-甘）与功能基团（巯基）。
