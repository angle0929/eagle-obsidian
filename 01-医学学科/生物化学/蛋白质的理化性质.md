# 蛋白质的理化性质

> 本章地位：把蛋白质"当作物质"来研究——它的电学行为、胶体行为、变性行为与显色行为，每一条都对应实验室或临床的一种应用。
> 电学性质的化学基础见 [[酸与碱]]；与氨基酸共有的性质见 [[蛋白质的分子组成]]。

本章五条理化性质总览：

```
蛋白质的理化性质
├─ 两性电离（→ 等电点 pI，电泳分离的依据）
├─ 胶体性质（→ 盐析沉淀，可逆）
├─ 空间结构破坏 → 变性 / 复性 / 凝固（→ 消毒灭菌、疫苗冷链）
├─ 紫外特征吸收（→ 280nm 定量，紫外分光光度法）
└─ 呈色反应（→ 茚三酮 / 双缩脲 / Folin-酚，定量与水解程度检测）
```

## 一、两性电离与等电点（考名解）

- 蛋白质分子除**两端的氨基和羧基**可解离外，氨基酸残基**侧链**中某些基团在一定 pH 下也可解离成带正/负电荷的基团。
- **等电点(isoelectric point, pI)**：当蛋白质溶液处于某一 pH 时，蛋白质解离成正、负离子的**趋势相等**，即成为**兼性离子，净电荷为零**，此时溶液的 pH 称为蛋白质的等电点。

```
pH < pI：Pr-NH3+-COOH   净电荷为正
pH = pI：Pr-NH3+-COO⁻   兼性离子（净电荷 = 0）
pH > pI：Pr-NH2-COO⁻    净电荷为负
```

- ⚠️ 表述口径（老师提醒）：**只问 pI 时，主语改为"蛋白质和氨基酸等两性电解质"**——pI 不是蛋白质独有，氨基酸同样具有。
- 应用：pI 时蛋白质溶解度最低、最易沉淀；偏离 pI 的程度决定电泳行为（推断：电泳原理为教材通识）。

## 二、胶体性质与沉淀

- 蛋白质属生物大分子（分子量 1 万~100 万），分子直径 **1~100nm**，恰在**胶粒**范围（胶体分散系统：分散质粒子某方向线度 1~100nm 的分散系统）。
- **蛋白质胶体稳定（可溶）的两个因素**：
  1. 颗粒**表面电荷**（同种电荷相互排斥）；
  2. **水化膜**（水分子包裹颗粒）。
- 破坏任一因素（调节 pH 至等电点，或脱水）→ 蛋白质颗粒聚集**析出**。
- **可逆沉淀（不变性沉淀）**：仅破坏水化膜/电荷使蛋白析出，蛋白**未变性**，过程**可逆**——典型：**盐析法**（试剂：**(NH₄)₂SO₄ 或 Na₂SO₄**）。

## 三、变性、复性与凝固

| 概念 | 定义 | 本质/要点 |
|---|---|---|
| **变性**(denaturation) | 在某些物理和化学因素作用下，蛋白质的**特定空间构象被破坏**（有序空间结构变无序），导致**理化性质改变和生物活性丧失** | 本质：破坏**非共价键和二硫键**，**不涉及氨基酸序列（一级结构）改变** |
| **复性**(renaturation) | 变性程度**较轻**时，去除变性因素后蛋白恢复或部分恢复原有构象和功能 | 例：牛核糖核酸酶（尿素 + β-巯基乙醇处理后再去除，详见 [[蛋白质结构与功能的关系]]） |
| **凝固**(protein coagulation) | 蛋白质变性后的絮状物**加热**可变成比较坚固的凝块，不易再溶于强酸和强碱 | 凝固是变性的"不可逆化"表现 |

- **变性因素**：加热、有机溶剂（如乙醇）、强酸、强碱、重金属离子及生物碱试剂等。
- **临床应用**：
  - 消毒灭菌——医用酒精使病原体蛋白**变性**；
  - **疫苗冷链**——防止疫苗蛋白**变性**失活（保存运输全程冷藏）。

**变性 / 沉淀 / 凝固三者关系辨析（易错，必背）**：

| 命题 | 判断 |
|---|---|
| 凝固一定变性 | **成立** |
| 变性不一定沉淀 | **成立** |
| 沉淀不一定变性 | **成立**（如盐析为不变性沉淀） |

> 机理串讲：变性后疏水侧链暴露、肽链相互缠绕聚集，易于从溶液析出（变性易沉淀）；但沉淀可以只破坏胶体稳定因素（盐析）而不触及构象——两条通路独立，故三个"一定/不一定"如上。

## 四、紫外光谱区特征性吸收

- 依据：蛋白质含**共轭双键**的**酪氨酸、色氨酸、苯丙氨酸**残基 → 在 **280nm** 波长处有特征性吸收峰。
- **OD₂₈₀ 与蛋白质浓度呈正比** → **紫外分光光度法（UV 法）**快速定量蛋白质。
- 氨基酸层面的吸收顺序（Trp 280 > Tyr 275 > Phe 257）见 [[蛋白质的分子组成]]——蛋白质的 280nm 吸收正是这些残基贡献的加和。

## 五、呈色反应（三种对比，必背对象与用途）

| 反应 | 对象 | 条件 | 现象/产物 | 用途 |
|---|---|---|---|---|
| **茚三酮反应** | **氨基酸 + 蛋白质**（水解后产生的氨基酸也可） | 弱酸性溶液共热 | **蓝紫色化合物**（570nm） | 氨基酸/蛋白定性定量 |
| **双缩脲反应** | **仅蛋白质和多肽**（独有肽键） | **稀碱溶液中与硫酸铜共热** | **紫色或红色** | 检测**蛋白质水解程度**（肽键越多色越深） |
| **Folin-酚试剂反应**（Lowry 法） | **仅蛋白质** | 碱性条件 + 酚试剂（磷钼酸与磷钨酸混合物） | **蓝色化合物（钼蓝）** | 蛋白定量；反应基团为带酚羟基的 **Tyr（及 Trp）残基** |

- 记忆抓手：茚三酮最广（氨基酸也有）；双缩脲抓**肽键**；Folin-酚抓**酚羟基（Tyr/Trp）**。

## 考点提示

- **名解**：等电点（注意主语"蛋白质和氨基酸等两性电解质"）、变性、复性。
- **选择**：胶体稳定的两因素（表面电荷 + 水化膜）；变性本质（非共价键 + 二硫键，一级结构不变）。
- **判断/选择**：凝固一定变性、变性不一定沉淀、沉淀不一定变性——三连辨析。
- **应用题**：280nm 定量（紫外分光光度法）；盐析试剂 (NH₄)₂SO₄ 为可逆沉淀；酒精消毒与疫苗冷链的生化解释。
- **对比题**：三种呈色反应的对象、条件、颜色、用途。
