# 蛋白质的分子结构

> 本章地位：全章骨架。蛋白质的结构是**层层组装**的——用"从线到体"的进化式视角掌握，每一层只记住：定义（覆盖范围）+ 主要化学键 + 典型例子。
> 组成的原材料见 [[蛋白质的分子组成]]；结构如何决定功能见 [[蛋白质结构与功能的关系]]。

## 〇、结构层次总览（进化式主线）

```
一级结构（氨基酸序列，肽键）
  └─ 二级结构（主链局部构象，氢键）
      ├─ 模体 / 超二级结构（二级结构的规律组合：αα、ββ、βαβ）
      └─ 三级结构（整条肽链全部原子空间排布，氢键/疏水/离子键/范德华力/二硫键）
          ├─ 结构域（三级结构内折叠较紧密、可独立功能的区域）
          └─ 四级结构（亚基的空间排布，氢键/离子键）——并非所有蛋白都有
```

**一张表看懂五个层次**（对比式总表）：

| 层次 | 定义（覆盖范围） | 主要化学键 | 常考例子 |
|---|---|---|---|
| **一级** | N 端至 C 端的**氨基酸线性排列顺序** | **肽键** | 牛胰岛素（A 链 21 + B 链 30 残基） |
| **二级** | 多肽链**主链局部**构象（不涉及 R 侧链） | **氢键** | α-螺旋、β-折叠、β-转角、无规卷曲 |
| **三级** | **整条肽链**全部氨基酸残基的相对空间位置（所有原子的三维排布） | 氢键、疏水作用力、离子键、范德华力、**二硫键** | 肌红蛋白 Mb |
| **四级** | **各亚基**的空间排布及亚基接触部位的布局与相互作用 | 氢键、**离子键** | 血红蛋白 Hb（α₂β₂ 四聚体） |
| 介于二、三级之间 | 模体（二级结构组合）/ 结构域（局部三级功能区） | — | 锌指结构 / 纤连蛋白 |

## 一、一级结构

- **定义**：蛋白质分子中从 N-端至 C-端的**氨基酸线性排列顺序**。
- **主要化学键：肽键**。
  - ⚠️ 口径变更（重要）：教材传统表述为"肽键、二硫键"，**任课老师已修改为仅"肽键"**（删除二硫键）——考试以课件口径为准；二硫键归入三级结构维系力。
- 典型例子：**牛胰岛素**——A、B 两条链，分别含 21、30 个氨基酸残基。
- 地位：一级结构是蛋白质**空间构象**和**特异生物学功能**的基础，但**不是**决定空间构象的唯一因素（分子伴侣等也参与，见下文）。

## 二、二级结构

**定义**：多肽链**主链的局部构象**，即该段肽链**主链骨架原子的相对空间位置**（**不涉及 R 侧链**的空间排布）。**主要化学键：氢键**。

### 1. 前置概念：肽单元

- 参与肽键的 **6 个原子**（Cα1、C、O、N、H、Cα2）位于**同一平面**，Cα1 与 Cα2 处于**反式(trans)构型**——此平面即**肽单元(peptide unit)**。
- 速记：**肽单元(6 原子) = 肽键四原子 + 左右两个 Cα**。
- 肽单元 Cα 所连两个**单键的自由旋转角度**决定了相邻肽单元平面的相对空间位置 → 主链呈现多样构象，形成不同的二级结构。

### 2. 四种常见二级结构（对比表，必背）

| 形式 | 形态 | 关键参数 | 维系作用力（氢键方向） | R 侧链位置 |
|---|---|---|---|---|
| **α-螺旋** | 右手螺旋 | **3.6 个氨基酸/圈；螺距 0.54nm** | 氢键，**与长轴基本平行** | 伸向螺旋**外层** |
| **β-折叠** | 锯齿状片层（多肽链充分伸展） | 分**平行**与**反平行**两种 | 氢键，**与长轴基本垂直** | 交错于锯齿状结构**上下方** |
| **β-转角** | 180° 回折 | **4 个氨基酸残基**组成；**第 2 个常为脯氨酸** | 氢键（第 1、4 残基的羰基氧与氨基氢配对） | 位于转角结构**外侧** |
| **无规卷曲** | 无确定规律性的肽链结构 | — | — | — |

> 拓展（了解）：二级结构远不止四类，还有 3₁₀-螺旋（螺距 0.6nm，比 α-螺旋紧密）、π-螺旋（螺距 0.52nm，不稳定）、2₇-二重带、β-凸起（存在于反平行 β-折叠片中）等。
> 辨析小技巧：α-螺旋与 β-折叠的氢键方向（平行 vs 垂直长轴）是最易混点；β-转角与无规卷曲的区别在于"回折的规律性"。

## 三、模体（超二级结构）——二级结构的组合（考名词解释）

- **定义**：两个或三个具有各自二级结构的肽段，在空间上相互接近、相互作用，形成**有规律的二级结构组合**，称超二级结构，又称**模体(motif)**。
- **最常见 3 种形式（选择题常考）**：**αα、ββ、βαβ**。
- 模体往往对应特征性的**一级结构（氨基酸序列）**，并发挥**特殊功能**——"序列 + 结构 + 功能"三位一体。
- **必记例子**：
  - **钙结合蛋白的钙离子结合模体**：α-螺旋-环-α-螺旋（**α-loop-α**，即 EF 手）。
  - **锌指结构**：一个 **α-螺旋** + **2 个反平行的 β-折叠**，广泛存在于 DNA 结合蛋白中。

## 四、三级结构

**定义**：**整条肽链**中全部氨基酸残基的相对空间位置——肽链中**所有原子**在三维空间的排布。由 **R 侧链间的相互作用 / R 侧链与主链的相互作用**维系。**主要化学键：氢键、疏水作用力、离子键、范德华力、二硫键**。

### 1. 结构域（考名解）

- **定义**：分子质量较大的蛋白质，其三级结构可分割为一个或数个**折叠得较为紧密、各行其独立功能**的区域。
- 要点：
  - 结构域与分子其余部分以**共价键**相连，具有**相对独立**的空间构象和生物学功能（结构域是分子的一部分）。
  - 同一蛋白可含不同结构域；不同蛋白可含相同结构域。
  - 常含 **100~200** 个序列上连续的氨基酸残基。
- 例子：**纤连蛋白**——两条多肽链，每条分为 7 个结构和功能相对独立的片段（结构域）。

### 2. 模体 vs 结构域（课件自带对比，整合如下）

| | 模体 (motif) | 结构域 (domain) |
|---|---|---|
| 结构层次 | 多个**二级结构**组合呈现的规律性结构单位 | **三级结构**层次上的局部折叠功能区（残基数约 40~400） |
| 命名依据 | 常**基于结构**命名（helix-turn-helix、zinc finger、leucine zipper） | 常**基于功能**命名（catalytic / regulatory / transmembrane domain） |
| 功能 | 多为 DNA 结合模体，广泛存在于 DNA 结合蛋白中 | 如催化域即酶分子中主要表现催化活性的立体结构区域 |
| 尺度记忆 | 二级结构 < **模体** < 结构域 ≤ 三级结构 | |

### 3. 分子伴侣（常考）

- **定义**：一大类参与**肽链折叠**、蛋白质**高级空间构象形成**的特殊蛋白质。
- 要点：
  - 促成**非共价组装**（高级空间构象），但本身是**非永久组分**（不留在最终产物中）。
  - 三类高度保守蛋白家族：**Hsp70、伴侣蛋白、核质蛋白**（作用机制在"第十二章 蛋白质的生物合成"展开）。
- 意义：解释"一级结构不是决定空间构象的唯一因素"。

## 五、四级结构

**定义**：蛋白质分子中**各亚基的空间排布**及**亚基接触部位的布局和相互作用**。**主要化学键：氢键、离子键**。

- **亚基(subunit)**：每条具有完整三级结构的多肽链。**单独的亚基一般无生物学功能**。
- 部分蛋白质需要两条或多条多肽链才能行使功能；**不是所有蛋白质都具有四级结构**。
- 例子：**血红蛋白 Hb 的四级结构——四聚体：2 个 α 亚基（α₁、α₂）+ 2 个 β 亚基（β₁、β₂）**；单个亚基称珠蛋白，无生物学功能（详见 [[蛋白质结构与功能的关系]]）。
- 聚合方式：**同 N 聚体**（相同亚基）与**异 N 聚体**（不同亚基，如 Hb）。

## 六、蛋白质的分类（了解）

- 按组成：**单纯蛋白质**；**结合蛋白质 = 蛋白质部分 + 非蛋白质部分**（辅基）。
- 按形状：**纤维状蛋白质**；**球状蛋白质**。

## 考点提示

- **名解**：模体（超二级结构）、结构域、分子伴侣、亚基。
- **选择**：各级结构的主要化学键（一级=肽键⚠️按老师口径；二级=氢键；三级=氢键/疏水/离子/范德华/二硫；四级=氢键/离子键）。
- **选择**：模体三种常见形式（αα、ββ、βαβ）；模体例子（α-loop-α 钙结合模体、锌指结构）。
- **数字题**：α-螺旋 3.6 残基/圈、螺距 0.54nm；β-转角 4 残基、第 2 位常为 Pro；结构域 100~200 残基；Hb 为 α₂β₂ 四聚体。
- **易混辨析**：模体 vs 结构域（命名依据：结构 vs 功能）；二级结构四种形式的氢键方向与 R 侧链位置。
