# 求导

1. $C'=0$
2. $(x^{\alpha})'=\alpha x^{\alpha-1}$
3. $(\sin x )'=\cos x$
4. $(\cos x)'=-\sin x$
5. $(\tan x)'=\sec^2 x$
6. $(\cot x)'=-\csc^2 x$
7. $(\sec x)'=\sec x \cdot \tan x$
8. $(\csc x)'=-\csc x \cdot \cot x$
9. $(\alpha^x)'=\alpha^x \cdot \ln \alpha \Rightarrow (e^x)'=e^x$
10. $(\log_{\alpha} x)'=\frac{1}{x \cdot \ln \alpha} \Rightarrow (\ln x)'=\frac{1}{x}$
11. $(\arcsin x)'=\frac{1}{\sqrt{1-x^2}}$
12. $(\arccos x)'=-\frac{1}{\sqrt{1-x^2}}$
13. $(arctan x)'=\frac{1}{1+x^2}$
14. $(arccot x)'=-\frac{1}{1+x^2}$
15. $(\ln x ) '=\frac{1}{x}$

# 微分

1. $dC'=0$
2. $dx^{\alpha}=\alpha x^{\alpha-1}dx$
3. $d\sin x =\cos x dx$
4. $d\cos x=-\sin xdx$
5. $d\tan x=\sec^2 xdx$
6. $d\cot x=-\csc^2 xdx$
7. $d\sec x=\sec x \cdot \tan xdx$
8. $d\csc x=-\csc x \cdot \cot xdx$
9. $d\alpha^x=\alpha^x \cdot \ln \alpha dx \Rightarrow de^x=e^xdx$
10. $d\log_{\alpha} x=\frac{1}{x \cdot \ln \alpha} dx\Rightarrow d\ln x=\frac{1}{x}dx$
11. $d\arcsin x=\frac{1}{\sqrt{1-x^2}}dx$
12. $d\arccos x=-\frac{1}{\sqrt{1-x^2}}dx$
13. $darctan x=\frac{1}{1+x^2}dx$
14. $darccot x=-\frac{1}{1+x^2}dx$
15. $d\ln x =\frac{1}{x}dx$

2. $\frac{\ln x + 1}{x^2} dx = d \frac{\ln x}{x}$

# 积分

1. $\int 0 dx =C$
2. $\int x^{\alpha} dx = \frac{1}{\alpha + 1} x^{\alpha+1}+C$
3. $\int e^x dx=e^x +C$
4. $\int \alpha^x dx =\frac{\alpha^c}{\ln \alpha} +C$
5. $\int  \frac{1}{x}dx=\ln |x| +C$
6. $\int \cos x dx=\sin x +C$
7. $\int \sin x dx=-\cos x +C$
8. $\int sec^2x dx=\tan x +C$
9. $\int csc^2x dx=-\cot x +C$
10. $\int secx \cdot tanx dx=\sec x +C$
11. $\int \cot x \cdot \csc x dx=-\csc x +C$
12. $\int \frac{dx}{\sqrt{1+x^2}}=\tan x +C$
13. $\int \frac{dx}{\sqrt{1-x^2}}=\sin x +C$

## 基本性质

1. $[\int f(x)dx]'=f(x)$
2. $\int f'(x)dx =f(x)+C , \int df(x)=f(x) +C$(“1”可以不写)
3. $\int [f(x)+g(x)]dx = \int f(x) dx +\int g(x)$
4. $\int kf(x) dx=k \int f(x)dx$

## 常用的积分公式（只能记结论，不好推导）

1. $\int \tan x dx=-\ln |\cos x| +C$
2. $\int \cot x dx=\ln |\sin x| +C$
3. $\int \sec x dx =\ln |\sec x + \tan x| +C$
4. $\int csc x dx =\ln |csc x - \tan x| +C$
5. $\int \frac{dx}{\alpha^2 + x^2}=\frac{1}{\alpha} \arctan \frac{x}{\alpha}+C$
6. $\int \frac{dx}{x^2-\alpha^2}=\frac{1}{2a} \ln|\frac{x-a}{x+a}|+C$
7. $\int \frac{dx}{sqrt{a^2-x^2}}=\arctan \frac{x}{a}+C$
8. $\int \frac{dx}{\sqrt{x^2-\alpha^2}}=\ln |x+\sqrt{x^2-\alpha^2}|+C$
9. $\int \frac{dx}{\sqrt{x^2+\alpha^2}}=\ln |x+\sqrt{x^2+\alpha^2}|+C$

## 换元法

### 凑微分法

1. $dx=\frac{1}{a}d(ax + b)$
2. $x^{n-1}dx=\frac{1}{an}d(ax^n + b)$
3. $\frac {1}{\sqrt{x}}=2d \sqrt{x}$
4. $\frac{1}{x}dx=d(\ln |x|)$
5. $e^x dx=de^x$
6. $\sin x dx=-d \cos x,\cos x dx=d \sin x$

### 三角代换中常见方法

1. 含有$\sqrt{\alpha^2-x^2}$时，令$x=a\sin t$
2. 含有$\sqrt{\alpha^2+x^2}$时，令$x=a\tan t$
3. 含有$\sqrt{x^2-\alpha^2}$时，令$x=a\sec t$

## 有理函数的积分

### 注意判断$\Delta＞0$与否

### 记

1. $\int \frac{dx}{x-a}=\int |x-a| +C$
2. $\int \frac {dx}{(x-a)^k}= \frac {1}{(1-k)(x-a)^{k-1}}+C$
3. 
	(3)
	$\int \frac{Ax+B}{x^2+px+q}\mathrm{d}x = \int \frac{Ax+B}{\left(x+\frac{p}{2}\right)^2 + \frac{4q-p^2}{4}}\mathrm{d}x$
	$令t = x + \frac{p}{2}，并记r^2 = \frac{4q-p^2}{4}，N = B - \frac{pA}{2}，则$
	$\int \frac{Ax+B}{x^2+px+q}\mathrm{d}x = \int \frac{Ax+B}{(x+\frac{p}{2})^2+\frac{4q-p^2}{4}}dx=A\int \frac{t\mathrm{d}t}{t^2+r^2} + N\int \frac{\mathrm{d}t}{t^2+r^2}= \frac{A}{2} \ln(t^2+r^2) + \frac{N}{r}\arctan\frac{t}{r} + C$
	(4)
	同(3)可得（$k\geq2$），
	$\int \frac{Ax+B}{(x^2+px+q)^k}\mathrm{d}x = A\int \frac{t\mathrm{d}t}{(t^2+r^2)^k} + N\int \frac{\mathrm{d}t}{(t^2+r^2)^k}$$= \frac{A}{2(1-k)(t^2+r^2)^{k-1}} + N\int \frac{\mathrm{d}t}{(t^2+r^2)^k}$
	记$I_k = \int \frac{\mathrm{d}t}{(t^2+r^2)^k}$，则利用分部积分法有递推公式:
	$I_k = \frac {t}{2r^2(k-1)(t^2+r^2)^{k-1}} + \frac {2k-3}{(t^2+r^2)^k} I_{k-1}$
	其中$I_1 = \int \frac{1}{t^2+r^2}\mathrm{d}t = \frac{1}{r}\arctan\frac{t}{r} + C$。
	 我们把这种方法叫做部分分式积分法。利用该法可以求出任何一个真分式的积分，从而也就可以求出任何一个有理函数的积分。
