# 宣传工作的基石

## 四维度

1. 文字：文稿
	1. 计划与纪要：方案、会议记录、访谈题纲
	2. 过程与数据：调查问卷、原始数据、观察笔记
	3. 反思与总结：个人日记（青鸟日志）、阶段小结、最终报告
	- 及时、规划、客观、准确
2. 影像：视频、照片
	```
	活动筹备，工作过程，人物特写，前后对比
	```
3. 实物：工具、道具（备忘录，语音转文字）
	```
	学生作品，签名物件，特色样本
	```
4. 数字：e.g.15天……
	```
	推文，新闻稿，新媒体
	```

# 摄影

## 三要素

1. 主题明确
2. 构图简洁
3. 光线事宜
