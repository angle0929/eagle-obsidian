# 性质

图书馆志愿者服务队是由志愿从事图书馆服务的在校生组成的***非营利性***校级团体，隶属于***图书馆读者服务部***，图书馆志愿者服务队挂靠于***志工中心***

# 场馆志愿者团队

1. 基本情况：
	1. 组成结构
		- 指导老师：王兴兰、李铭
		- 2名副队长
		- 28个常规班次（每班2名组长）
	2. 每天四个班次，每个班次工作3小时
2. 工作内容：
	1. 门岗出入口引导
	2. 帮助同学借还书，及时上架归还书籍，整理责任书架
	3. 维持图书的流通
	4. 完成巡逻巡查工作，维护良好的阅读学习环境
	5. 反馈读者意见和建议，帮助改进图书馆工作和服务队建设
	6. 定期开展图书馆志愿者培训，读者培训，“读书月”系列活动以及文献检索相关讲座等，传播和推广图书馆文化

# 阅读推广志愿者团队

1. 基本情况：
	- 指导老师：徐倩、肖廷超

1. 责任心、文明有礼、服从安排；不迟到早退，***提前15分钟***到岗
2. 每学期至少做***满16次***，做满***2学期***才可以参加时长认定，***3学期***才可以参与*社会实践*时长认定
3. 严禁私自换班替班，违者将被清退
4. 工作时间段
	- 上午9:00 - 12:00
	- 中午12：00-15：00
	- 下午15：00-18：00
	- 晚上提前班18:00 - 21:00
	- ，晚上19:00 - 22:00

# 工作会面临的情况

1. 读者出图书馆的时候引发警报
	1. 志愿者人脸识别以解除警报
	2. 检查是否有馆内借阅书籍
		1. 若没有，则对读者的电子设备、银行卡、新书依次过门，排除原因
		2. 若有馆内书籍，也要依次过门，查找问题书籍，辅助读者对问题书进行借阅以消磁
		3. 已经借阅，但是是永磁书的处理
			1. 让读者尽量找一本相同但较新的书，找到后，要对原本的永磁书进行归还操作
			2. 若没有，则要确认该书已经被借阅，然后从检测门旁将书递给读者，并提醒：为看完后再将此书归还，平时不要带到图书馆，以免报警引起误会
			3. 若读者不借阅此书，则要确认此书已经被归还，并将无借阅记录的永磁书放到前台的永磁书存放处
2. 进入图书馆除了人脸识别还可以刷还可以刷微信公众号“重庆医科大学财务处”的消费二维码
