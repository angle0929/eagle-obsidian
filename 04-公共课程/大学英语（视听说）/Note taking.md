# 记哪些

1. key words, topic
2. logic words(逻辑词)
3. when, where, who（name profession）
4. numbers: date→calculations
5. attitude，reason

# 原则

∵由于别人说话的速度远大于你写字的速度
∴笔记要concise(简要，简洁)，大多数时候甚至**词语只写半截**→学习通上1.2有关键词缩写（abbreviations）

# 经验积累

#缩写abb
1. the forth of july →7.4→==日期全部写成数字==
2. for→4 ∴数字4在缩写中有多种意思，注意区分→==数字可以代替单词==
3. as soon as possible→ASAP（大小写都可以）→==短语可以用每个单词的首字母书写=
4. yr→your
5. part→partner
6. lrn→learn→==省略元音==
7. sts→students  那么是否st→student

# 考试方法

1. 勾画每个选项的关键词
2. 根据选项推断该题应该侧重听的信息：词性，时间地点人物，单复数
