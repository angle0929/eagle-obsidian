# 导论

## “六个必须坚持”（习思想的世界观、方法论和贯穿其中的立场观点方法的重要体现）*

1. 坚持人民至上
	1. 根本价值立场
	2. 体现了历史唯物主义群众史观
	```
在历史中找到客观规律：人民群众创造历史
	```
2. 坚持自信自立
	1. 内在精神特质
	2. 体现了客观规律性和主观能动性的有机结合
	```
在客观规律下的自行
	```
3. 坚持守正创新
	1. 鲜明理论品格
	2. 体现了变与不变、继承与发展的内在联系
	```
e.g.
魂脉：马克思主义基本原理
根脉：中华优秀传统文化
“两个结合”：
4. 把马克思主义基本原理同中国具体实际相结合
5. 马克思主义基本原理同中华优秀传统文化相结合
	```
6. 坚持问题导向
	1. 时间要求
	2. 体现矛盾的普遍性与客观性
	```
对症下药
	```
7. 坚持系统观念
	1. 基本思想和工作方法
	2. 体现辩证唯物主义普遍联系的原理
	```
万事万物普遍联系，多方面看实物
	```
8. 坚持胸怀天下
	1. 中国共产党人的境界格局
	2. 体现了马克思主义追求人类进步和解放的崇高理想

# 第一章

## 坚定中国特色社会主义道路、理论、制度、文化自信

看书$P_{20、21}$

## 统筹推进“五位一体”总体布局和“四个全面”

### 怎样坚持和发展中国特色社会主义

1. 全面贯彻党的基本理论、基本路线、基本方略
2. 统筹推进“五位一体”总体布局和协调推进“四个全面”战略布局
3. 以咬定青山不放松的定力持续奋斗

### “五位一体”

经济、政治、文化、社会、生态
宏观，各个领域之间→总体布局

### ”四个全面“

全面深化改革、全面依法治国、全面建成小康社会、全面从严治党
某个领域上→战略布局

# 第二章

## 实现中华民族伟大复兴梦的本质内涵*

1. 国家富强
	1. 在全面建成小康社会的基础上，全面建成富强民主文明和谐美丽的社会主义现代化强国
2. 民族振兴
	1. 使中华民族更加坚强有力地自立于世界民族之林
	2. 为人类做出新的更大的贡献
3. 人民幸福
	1. 坚持以人民为中心
	2. 增进人民福祉，促进人的全面发展，朝共同富裕方向稳步前进

# 第三章

## 如何理解党的领导是全面的、系统的、整体的*

1. 中国共产党作为最高政治领导力量，在党和国家事业发展中居于中心地位。党的领导是全面的、系统的、整体的，必须贯穿到治国理政的方方面面。
2. 党的领导是全面的。在领导对象上，党领导人大、政府、政协、检察机关等；在领导内容上，党领导经济建设、政治建设、文化建设、社会建设、生态文明建设等；在领导方式上，党通过指定大政方针，提出立法建议，推荐重要干部，进行思想宣传等
3. 党的领导是系统的。党在推进各项事业发展中发挥着把方向、谋大局、订政策促改革的作用，通过总揽全局、协调各方，把党的领导落实到国家治理各领域各方面各环节
4. 党的领导是整体的。党要完整发挥领导功能。党的领导作为一个统一整体是不可分割的，必须按照民主集中制原则，层层体现到治国理政的全过程各方面。党委在同级各种组织中其领导核心作用，在党委统一领导下尽心尽力做好自身职责范围内的工作
5. 党的领导是全面的、系统的、整体的，并不是说党组织包揽包办一切，而是在各级各种组织中发挥领导核心作用，使党的领导作用贯穿

# 第四章

## 新时代如何坚持党的人民立场

1. 要始终牢记党的初心和使命（为中国人民谋幸福，为中华民族谋复兴）
2. 要始终保持党同人民群众的血肉联系
	1. 中国共产党的最大政治优势使密切联系群众
3. 要热爱人民、尊重人民、敬畏人民

# 第五章

## 国家治理体系和治理能力（包含在下一条）

## 谈一谈统筹推进各领域各方面改革开放

### 坚持全面深化改革总目标

#### 总目标

1. 完善和发展中国特色社会主义制度（改革的根本方向）
2. 推进国家治理体系和治理能力现代化（改革的鲜明指向和时代要求）

#### 全面深化改革必须牢牢把握总目标，实施好”六个紧紧围绕“的路线图

#### 统筹推进各领域各方面改革开放，必须以全面深化改革总目标为引领、以制度建设为总路线、以经济制度改革为重点，以哦藏药领域二号关键环节改革为突破口，使各方面改革协同推进、环环相扣、形成合力

### 推进国家治理体系和治理能力现代化

国家治理体系和治理能力使一个国家制度和制度执行能力的集中体现，是一个有机整体，有了好的国家治理体系才能提高国家治理能力，提高国家治理能力才能充分发挥国家治理体系的效能（完整性）

#### 国家治理体系

1. 是在党领导下管理国家的制度体系
2. 包括经济、政治、文化、社会、生态文明和党的建设等==各领域体制机制、法律法规安排==

#### 国家治理能力

1. 是运用国家制度管理社会各方面事务的能力
2. 包括改革发展稳定、内政外交国防、治党治国治军等各方面

# 第六章

## 社会主义基本经济制度的新概括

1. 公有制为主体、多种所有制经济共同发展
2. 按劳分配为主体、多种分配方式并存
3. 社会主义市场经济体制

1. 高质量发展为全面建设社会主义现代化国家提供更为坚实的物质基础
2. 高质量发展是不断满足人民对美好生活需要的重要保证
3. 高质量发展是维护国家长治久安的必然要求

# 第七章

## 在坚持教育发展、科技创新、人才培养良性循环中必须深入学习哪些重要战略

1. 科教兴国战略
	1. 要全面落实科学技术是第一生产力的思想，坚持教育优先发展，把科技和教育作为经济社会大战的重中之重
2. 人才强国战略
	1. 要牢固树立人才资源是第一资源的理念，把人才队伍建设提升到郭建战略的高度
3. 创新驱动发展战略
	1. 要坚持创新是第一动力

# 第八章

## 如何认识“全过程人民民主是社会主义民主政治的本质属性”

### 全过程人民民主是社会主义政治的伟大创造

1.  全过程人民民主是过程民主和成果民主的统一（流程与成效的统一）
2. 全过程人民民主是程序民主和实质民主的统一
3. 全过程人民民主是直接民主和间接民主的统一
4. 全过程人民民主是人民民主和国家意志的统一

### 全过程人民民主是全链条、全方位、全覆盖的民主

1. 全链条的民主（民主环节的完整性）
	1. 民主选举环节
	2. 民主协商环节
	3. 民主决策环节
	4. 民主管理环节
	5. 民主监督环节
2. 全方位的民主
	1. 贯通国家政治生活和社会生活各层面各维度
	2. 全国、省级、设区的市级、县级、乡镇级五级人民代表大会。各级人大代表由民主选举产生，对人民负责、受人民监督；各级人大代表选举产生本级人大常委会、人民政府、监察机关、审判机关、检察机关领导人员和组成人员。
3. 全覆盖的民主
	1. 全过程人民民主涵盖国各项事业各项工作，贯穿”五位一体“总体布局和”四个全面“战略布局的方方面面，是各方面民主的有机统一

### 全过程人民民主是最广泛、最真实、最管用的民主

1. 最广泛的民主：
	1. 国家的一切权力属于人民
	2. 不同地域、不同领域、不同层级、不同群体均实现全面覆盖的民主体系
2. 最真实的民主
	1. 全过程人民民主把党的主张、国家意志、人民意愿紧密结合在一起，充分体现了人民的主体地位，彰显了人民民主的真实性
3. 最管用的民主
	1. 要用来解决人民要解决的问题
	2. 具有显著的实践优越性

# 第十章

## 如何坚持中国特色社会主义文化发展道路

1. 坚持举旗帜、聚民心、育新人、兴文化、展形象
	1. 举旗帜：高举马克思主义、中国特色社会主义的旗帜
	2. 聚民心：牢牢把握正确舆论导向，做大做强主流思想舆论
	3. 育新人：坚持立德树人、以文化人，建设社会主义精神文明，培育和践行社会主义核心价值观
	4. 兴文化：推动中华民族优秀传统文化创造性转化、创新性发展
	5. 展形象：推进国际传播能力建设，讲好中国故事
2. 坚持”二为“方向、”双百“方针
	1. 坚持为人民服务、为社会主义服务的根本方向
	2. 重要方针：坚持百花齐放、百家争鸣，是繁荣发展社会主义文化的重要方针
3. 激发全民族文化创新创造活力

# 第十一章

## 如何不断提高人民生活品质

### 完善分配制度

1. 发挥初次分配的基础性作用
	1. 努力提高劳动报酬在初次分配中的比重
	2. 健全工资合理增长机制，探索通过要素使用权、收益权增加中低收入群体要素收入
2. 发挥再分配的调节作用
	1. 加大税收、社保、转移支付等的调节力度，提高精准性
3. 建立健全第三次分配机制
	1. 引导、支持有意愿有能力的企业、社会组织和个人积极参与公益慈善事业

## “绿水青山就是金山银山”的科学内涵

2. 绿水青山既是自然财富、生态财富，又是社会财富、经济财富，还是人民群众健康的重要保障，是人民群众的共有财富
