# 时代背景

1. 世界史角度：世界百年未有之大变局***加速***演进
	1. 变：新一轮***科技革命***和***产业变革***深入发展
	2. 动荡
	补充：“两个大局”①世界百年未有之大变局②中华民族伟大复兴的战略全局
2. 中华民族史角度：**中华民族进入伟大复兴关键时期**
	习近平新时代特色社会主义思想，正是在中华民族迎来***从站起来、富起来到强起来***的伟大飞跃，实现中华民族伟大复兴进入***不可逆转***（主要矛盾的转换）的历史进程中创立并不断丰富发展的
3. 现代化发展史角度：中国式现代化全面推进拓展
	独特的文化传统、历史命运、基本国情→***中国必须走适合自己特点的现代化道路***
4. 社会主义发展史角度：**==科学==社会主义**在21世纪的中国焕发新的蓬勃生机←苏联解体
5. 党史角度：中国共产党自我革命开辟新的境界

## 主要内容

1. “十个明确”   主体内容、思想体系
	1. 中国特色社会主义***最本质的特征*** ：中国共产党领导
	2. 中国特色社会主义***制度的最大优势*** ：中国共产党领导
	3. 中国特色社会主义事业“五位一体”总体布局：经济建设、政治建设、文化建设、社会建设、生态建设
	4. ”四个全面“战略布局：$P_{6、7}$
		1. 全面建设社会主义现代化国家
		2. 全面深化改革的总目标：……
		3. 全面依法治国的总目标：……
		4. 全面从严治党
2. "十四个坚持"   重要组成部分、治国理政，构成基本方略
3. “十三个全面成就”   对新时代伟大实践进行科学总结，展示理论和实践成果
4. ==六个坚持==
	唯物主义和辩证法、认识论和实践论、真理论和简直论
	赋予时代内涵，彰显理论品格和鲜明特征
	1. 坚持人民至上
		1. 根本价值立场
		2. 历史唯物主义群众史观
			1. 在历史中寻找规律
			2. 人民群众创造历史
	2. 坚持自信自立
		1. 精神特质
		2. 客观规律和主观能动性
			1. 在客观规律下寻找自信
			2. 主观能动性→自立自强
	3. 坚持守正创新
		1. 理论品格
		2. 变与不变、继承与发展
			1. 不变、继承：e.g.魂脉、根脉
			2. 变、发展：改革开放
	4. 坚持问题导向
		1. 重要实践要求
		2. 矛盾的普遍性和客观性
			1. 矛盾长久存在→普遍性
			2. 矛盾客观存在→客观性
		e.g. 病→药
	5. 坚持系统观念
		1. 基本思想和工作方法
		2. 辩证唯物主义普遍联系的观念
			万事万物普遍联系，从多角度看待问题
	6. 坚持胸怀天下
		1. 中国共产党的境界格局
		2. 马克思主义追求***人类*** 进步和解放的崇高理想
