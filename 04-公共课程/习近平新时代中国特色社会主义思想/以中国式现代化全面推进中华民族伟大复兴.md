# 中华民族近代以来最伟大的梦想——实现中华民族伟大复兴

全面建成小康社会是实现中华民族伟大复兴的关键一步

## 实现中华民族伟大复兴的中国梦

2012年11月，习近平==首次==提出”中国梦“
一百年以来，中国共产党团结带领中国人民进行的一切奋斗、一切牺牲、一切创造，归结起来就是一个主题：实现中华民族伟大复兴
1. 本质：
	1. 国家富强
		要在全面建成小康社会的基础上，全面建成富强民主文明和谐美丽的社会主义现代化强国
		```
		富强民主文明和谐美丽即“五位一体”：
		富强——经济
		民主——政治
		文明——文化
		和谐——社会
		美丽——生态
		```
	2. 民族振兴
		要使中华民族更加坚强有力地自立于世界民族之林，为人类作出新的更大的贡献
	3. 人民幸福
		坚持以人民为中心，增进人民福祉，促进人的全面发展，朝着共同富裕方向稳步前进
2. 中国梦把国家的追求、民族的向往、人民的期盼融为一体
	- 要让每个人获得发展自我和奉献社会的机会
	- 共同享有人生出彩的机会
	- 共同享有梦想成真的机会
	- 共同享有同祖国和时代一起成长与进步的机会

## 全面建成小康社会

| 时间                  | 小康   | 用语   | 方面   |
| ------------------- | ---- | ---- | ---- |
| 二十世纪末1999年          | 总体小康 | 全面建设 | 经济   |
| 2021年中国共产党成立100周年大会 | 全面小康 | 全面建成 | 五位一体 |
```
小康——发展水平
全面——发展的平衡性、协调性、可持续性
```

## 全面建成现代化强国

```
两步走
	到1980年建成较完整的工业和国民经济体系
	到二十世纪末，实现工业、农业、国防和科技技术现代化
三步走
	1981-1990，解决人民温饱问题
	1991-二十世纪末，小康水平
	2000-二十一世纪中叶（2050），建成社会主义现代化强国
新三步走
	2000-2010，实现国民生产总值比2000年翻一番，使人民的小康生活更加宽裕，形成比较完善的社会主义市场经济体制
	2010-2021建党一百周年时，使国民经济更加发展，各项制度更加完善
	2021-2050，基本实现现代化，建成富强民主文明的社会主义国家
```
全面建成社会主义现代化强国总的战略安排，两步走
1. 到2035年，基本实现社会主义现代化
2. 在基本实现社会主义现代化的基础上，到本世纪中叶（2050），把我国建设成为富强民主文明和谐美丽的社会主义现代化强国
全面建成社会主义现代化强国总的战略安排，把基本实现社会主义现代化的时间提前了15年
```
在“新三步走”战略中，计划在2025年基本实现社会主义现代化，但现在时计划在2035年基本实现社会主义现代化
```
```
对中国特色社会主义战略安排的认识
1.连续性：后一个战略安排为前一个战略安排最后一步的深化
2.与时俱进：依据情况新制定
3.实事求是：“提前15年”
```
