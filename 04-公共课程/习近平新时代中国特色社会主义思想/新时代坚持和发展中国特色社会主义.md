# 中国特色社会主义新时代

## 历史方位

1. 基本内涵
	1. 历史脉络：是承前启后、继往开来、在新的历史条件下继续夺取中国特色社会主义伟大生理的时代
	2. 实践主题：是决胜全面建成小康社会、进而全面建设社会主义现代化强国的时代
	3. 人民性：是全国各民族团结奋斗、不断创造美好生活、逐步实现全体人民共同富裕的时代
	4. 民族性：是全体中华儿女勠心同力、奋斗实现中华民族伟大复兴的时代
	5. 世界性：是我国不断为人类作出更大贡献的时代
2. 意义：
	1. 中华民族复兴历史进程：意味着近代以来久经磨难的中华民族迎来了从站起来、富起来到强起来的伟大飞跃，迎来了实现中华民族伟大复兴的光明前景
	2. 科学社会主义历史进程：体味着科学社会主义在21世纪的中国焕发出强大生机活力，在世界上高高举起了中国特色社会主义伟大旗帜
	3. 人类文明进程：意味着中国特色社会主义道路、理论、制度、文化不断发展，拓展了发展中国家走向现代化的路径，给世界上那些既希望加快发展又希望保持自身独立性的国家和民族提供了全新选择我，为解决人类问题提供了中国智慧和中国方案
3. 进入新时代的依据：我国社会主要矛盾从人民日益增长的物质文化需要同落后的社会生产之间的矛盾转化为人民日益增长的美好生活需要和不平衡不充分妇女的发展之间的矛盾（党的十八大）
```
人民：全体人民
美好生活：安全感、幸福感、获得感
不平衡：区域与区域之间 e.g.上海和青海
不充分：各个领域各方面之间 e.g.人工智能与药物生产
```

## 社会主要矛盾变化是关系全局的历史性变化

1. 社会主要矛盾的重要性：
	1. 是各种社会矛盾的主要根源和集中反映
	2. 根据经济社会发展变化，适时对社会主要矛盾作出科学判断，并在此基础上提出==党的中心任务==，是推动党和国家事业不断向前发展的宝贵经验
2. 没有改变的：
	1. 没有改变对我国社会主义所处历史阶段的判断（社会主义初级阶段）
	2. 我国是世界上最大的发展中国家的国际地位没有改变

# 新时代坚持和发展中国特色社会主义要一以贯之

## 全面贯彻党的基本理论、基本路线、基本方略

事关党的前途命运，事关中国特色社会主义事业兴衰成败
1. 党的基本理论是坚持和发展中国特色社会主义的行动指南
	1. 怎么做：坚定马克思主义信仰，坚持马克思主义指导地位，坚持不懈用习近平新时代中国特色社会主义思想凝心铸魂，用党的基本理论指导实践，推动工作
2. 党的基本路线是国家的生命线，人民的幸福线、
	1. 是在深刻总结社会主义建设历史经验教训、看科学分析社会主义初级阶段主要任务的基础上探索形成的
	2. 社会主义初级阶段的基本路线：领导和团结全国各民族人民，坚持以经济发展为中心，坚持四项基本原则，坚持改革开放，自力更生，艰苦创业，为把我国建设成为富强民主文明和谐美丽的社会主义现代化强国
3. 基本方略
	1. 主要内容：“十四个坚持“
	2. 怎么做：坚持党的最高纲领和基本纲领的统一，坚持党治国理政的重大方针政策和原则，为实现第二个百年奋斗目标、实现中华民族伟大复兴中国梦而奋斗
