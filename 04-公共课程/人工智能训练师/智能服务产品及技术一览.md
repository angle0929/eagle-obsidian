# 常见的人工智能产品

1. 智能外呼：在特定情况自动发起外呼电话并完成与用户的简单交互-通知
2. 智能客服：通过语音助手等，用户和机器人惊醒交互，机器人根据用户的问题，通过语音识别，数据分析等技术处理后，反馈给用户相关的答案-回复、解决
3. 智能交通：通过信息技术、数据通信技术、电子控制技术和人工智能等科学技术综合用于交通
4. 智能物流：图像识别技术
5. 智能诊疗
6. 智能导航
7. 智能质检：e.g.结合之间规则、关键词检索、用户情绪识别等算法，【按段客服的答复是否符合客服要求
8. 智能阅读

# 人工智能产品的价值

1. 企业、政府
	1. 服务宽度：成本较低，补增多形态多渠道的服务模式
	2. 服务深度：通过客户的偏好，来源等数据挖掘分析，持续优化，提升整体客户体验
2. 用户
	1. 服务体验：根据客户反馈，提前预估用户需求，将被动服务转变为主动服务
	2. 服务价值转化：通过对用户个性化差异的数据挖掘，打造定制化产品或专属服务

# 人工智能的关键技术

1. 机器学习
2. 知识图谱
3. 自然语言处理
4. 人机交互
5. 生物特征识别

# 人工智能的发展方向

1. 可解释人工智能：人工智能渗透在生活的每个方面，透明性和可理解性对于用户而言非常重要
2. 单一智能向通用智能发展：覆盖多领域，消除各个零遇见的应用堡垒
3. 机器自主学习
