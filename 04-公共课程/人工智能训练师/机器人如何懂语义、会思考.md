# 人工智能的知识概述

# 人工智能的关键技术

1. 机器学习：在已知数据中找规律
	1. 监督学习：在指导下，根据有标准答案的数据进行学习
	2. 无监督学习：无指导下，自主寻找数据的共同特征，此处的数据没有标准答案
	3. 强化学习：无指导下，自主对问题的答案进行评价
2. 知识图谱：”实体——关系——实体“
	1. 本身是具有属性的实体
	2. 可以建立概念间的连接关系
	3. 改变只是检索方式
		1. 推理解锁概念知识
		2. 图形展示结构化知识
3. 自然语言处理（NLP）：人类语言和机器语言的桥梁，使机器拥有能够理解、处理、是哦那个人类语言的能力
	1. 消除语言的障碍：翻译
	2. 文本理解
	3. 智能问答
	4. 局限：
		1. 在语法、语义和语音等不同层面存在不确定性
		2. 新的词汇、语法、术语导致未知语言现象的不可预测性 e.g.网络用语
		3. 数据资源难以完全覆盖的语言现象
		4. 语义的模糊性和错综复杂的关联性难以用简单的数据模型表述

# 人工智能的风格设计

通过语言或文字交流的时候，给对方的直观感受：幽默风趣，语言严谨，专业
1. 人设/品牌定位：称呼、表情、动作、口头禅、风格
2. 语言风格拟人化：疲劳度、恢复机制、衔接过渡、千人千面
3. 服务标准统一：及时、长期、统一、高效
4. 学习和专业性能力强：自学习、大数据、技术性

# 数据智能推动人机协同

数据智能给嫩的目标使希望数据能驱动决策，让机器具有推理等认知能力
1. 业务数据化：
	1. 收集、检测和洞察阶段
	2. 通过数据描述、跟踪业务的发展
2. 业务智能化
	1. 决策、重塑阶段
	2. 大数据开始对业务环节进行改造，依靠数据、算法模型来提升业务效率
