## 四、链接体系

### 1. 三级索引（MOC）

```
00-主页.md                      ← 顶层入口，166 篇笔记全部可一键返回
 └─ 域总览 ×7                   ← 医学学科总览 / 科研课题总览 / … / 资源库总览
     └─ 专题索引 ×25            ← 系统解剖学 / 化学·TRIZ酰胺合成 / 相声 / …
```

- 新建 17 个专题索引，补全 15 个已有索引（如系统解剖学补入缺失的"神经系统总论"）
- 目录内笔记 < 2 篇时不建索引，改由父级直链，避免产生空壳索引

### 2. 每篇笔记的元数据与导航

```yaml
---
title: 渗透压
type: 笔记
domain: 医学学科
topic: 医用化学
tags: [医学学科, 医用化学]
created: 2025-10-14
updated: 2026-09-09
---
```

文末统一附加两条导航：

```
> 所属：[[医学学科总览]] › [[医用化学]] ｜ 返回：[[00-主页|主页]]
> 同专题：[[原电池]] · [[氧化还原反应]] · [[水]] · [[第四章 溶液]] …
```

`同专题` 建立了同目录笔记的横向互链，这是孤立笔记从 88 降到 0 的主要手段。

## 五、设计取舍说明

1. **不使用 Dataview**。检测确认本库未安装该插件（仅 table-editor、mind-map、keyword-highlighter、latex-suite、editing-toolbar、calendar），故索引全部采用静态 wikilink，不依赖任何插件即可正常工作。
2. **不移动图片到统一附件目录**。当前 `.obsidian/app.json` 中 `attachmentFolderPath: "./"`，图片与笔记同目录。此设置下整目录迁移不会破坏引用，保持了 192 个附件的引用完整性。若日后改为统一附件目录，需重新校验全部图片引用。
3. **保留原有正文标签**（如 `#医用化学`、`#日记`），仅在前台追加结构化字段，避免丢失你已有的标签习惯。
