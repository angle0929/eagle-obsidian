## 约定

- **分类主干**：用户明确指定三大类——读书笔记 / 医学学科 / 科研课题（化学、麻醉）。
- **链接方式**：静态 wikilink，不用 Dataview（本库未安装该插件）。已装插件：table-editor、mind-map、keyword-highlighter、latex-suite、editing-toolbar、calendar。
- **附件**：`attachmentFolderPath: "./"`，图片与笔记同目录。迁移笔记时必须整目录移动，否则断图。
- **MOC 规则**：顶层域用「<域名>总览.md」，子目录用「<目录名>.md」；目录内 md < 2 篇时不建索引。
- **每篇笔记**：顶部 YAML（title/type/domain/topic/tags/created/updated），底部两行导航（所属域 › 专题 ｜ 返回主页；同专题横向链接）。
- **日记**：顶部有 ‹ 上一篇 ｜ 日记总览 ｜ 下一篇 › 导航。
