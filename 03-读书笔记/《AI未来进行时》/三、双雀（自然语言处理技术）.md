# 双雀

双胞胎金雀（哥哥）、银雀（弟弟）分别由自己的AI伙伴阿托曼、索拉里斯。哥哥金雀急于证明自己，他的AI伙伴阿托曼就帮他提高自己的竞争力，参加各种比赛，利用竞技性游戏来调动金雀学习的主动性；而弟弟患有阿斯伯格综合征，抗拒肢体与目光接触，对生命和大自然更感兴趣。两人分别被精英家庭和艺术家庭领养。金雀在父母和兄弟姐妹都是同龄人中佼佼者的家庭里不断竞争，想要向父亲证明自己，成为像父亲一样的投资者，阿托曼也建立全面的自我评价模型，促进金雀全面发展；雷伊和安德烈斯则通过AI索拉里斯提供的数据反馈了解银雀对他们行为的心理活动，给银雀提供真正的爱，银雀则通过AI算法根据差异实时发调整参数，看世界中的各个文明、风景。孤儿院长金妈妈发现兄弟俩愈来愈远，在他们的AI伙伴的底层代码中让阿托曼和索拉里斯交互数据，通过AI伙伴拉回兄弟间的情谊。
- 人类唯一可能超越AI的领域，只可能在及其无法触及之处，那是属于人类感性与直觉的能力。
	```
	社交沟通、情感情绪，人类要真正学会读懂人类
	```
观后感：AI是科学数字计算，并且可以整合整个人类社会的信息，这造就了AI可以通过数据评估学生的学习情况，探索适合学生的学习方法，为学生整合更多的学习资源，提供丰富的学习、竞争途径，根据学生的性格爱好、目标实现个体定制教学；AI同时也是育德方面的好老师，就如《双雀》中的金雀、银雀双胞胎兄弟因阿托曼和索拉里斯的信息交互重建兄弟情谊。

# 开复解读

## 自然语言处理（NLP）

AI研究的目的是希望计算机拥有与人类一样的智慧和能力。自然语言是人类通过社会活动和教育过程习得的语言，包括说话、文字表达以及非语言的交流语言。深度学习技术可以轻松掌握复杂的词汇关系和语言模型，通过源源不断的数据汲取更多只是，进而实现能力的扩展，让AI拥有分析、理解和处理人类语言的能力

### 有监督的NLP

1. 自然语言识别：语言识别（语音→文字）、语音合成（文字→语音）、光学字符识别（手写体or图片→文字）
2. 自然语言理解
	```
	在自然语言处理领域，有监督的学习催生出一个新的职业——数据标注
	e.g. 【预定飞机航班】我想要上午8：38【起飞时间】从北京【出发地】起飞，上午11：10【抵达时间】落地上海【目的地】
	```

### 自监督的NLP

在训练NLP模型时，无须人工标注输出、输入数据，从而打破有监督学习的技术瓶颈。这种自监督学习方法名为“序列转导”。
第一个序列转导模型Transformer（2017）具备==选择性记忆机制==和==注意力机制==，选择性记住前文的重点及相关内容.这种NLP模型在学习语言时所依靠的不是人类语言学理论中的词性变化规律和语法规则，而是依靠AI自创的结构和抽象概念，从数据中汲取只是，然后将其嵌入一个巨大的神经网络。整个系统的训练数据完全来源于自然语言环境，没有经过人工标注。以丰富的自然数据和强大的数据处理功能为基础没系统可以建立自己的学习模式，进而不断强化自己的能力。
```
依靠人类语言学理论中的词性变化规律和语法规则学习语言不仅需要大量的人力分析、输入人类所有语种的语法知识，更需要大量的数据训练，进程缓慢，效果不明显（这也是为什么从20世纪50年代起NLP的研发进度迟迟没有进展）。直到深度学习技术横空出世，NLP技术才得以快速发展。
```

## NLP应用

2020年OpenAI发布的GPT-3有一个巨大的序列转导引擎，建立了一个庞大的神经网络模型来学习分析语言，在惊人的计算资源下（使用当时世界上最大的语言数据集——处理前容量超过45TB，而这个数据集还将以超过每年10倍的数据增加），人类开始在上面搭建各种应用程序
- 让用户和历史人类穿越时空对话的聊天机器人
- 根据用户按下的吉他音符自动完成后续乐曲创作的作曲器
- 可以补全照片的图像生成器
……
虽然目前这些应用程序都只停留在尝试阶段，但是未来这个平台还可能会成为类似于Windows或安卓的存在。除搭建对话式AI系统外，NLP平台还可能成为下一代搜索引擎。

## NLP能否成为AGI

目前人类仍在致力于制作弄够通过图灵测试的人工智能，实现通用人工智能（AGI）。
GPT-3的NLP是基于深度学习和神经网络、卷积神经网络等实现的，归根是在大量的数据训练下最求目标函数最大化，并不能实现人类智能的核心能力——思考、推理、规划和创造（现在GPT等AI 的自批评是按照被给定的人类观点生成的，并不是发自内心的自我反省及批评）
- 让机器真正拥有“智能”的前提是人类对大脑的运作方式和认知过程要有更深入的了解
- 提升机器“智能”的最佳途径是开发通用计算方式（如深度学习、GPT-3）

## 教育领域的AI

上课、练习、测评、辅导
- AI在教育领域最需要挖掘的潜能，就是为未来的孩子提供个性化的学习方式

### 人类教师承担的两个角色

1. 学生的个性化人生导师
	```
	人类教师有着机器所无法取代的人性光芒，能理解学生的心理及情绪，加上人类教师能够与在教学追踪承担重要性、标准化任务的AI助教无缝配合
	```
2. 对AI导师、AI伙伴的工作进行前瞻性的规划及指导，定义下一个阶段的目标，以便进一步满足学生的需求，甚至主动探索学生在未来可能出现的新需求，帮助学生拓展发发展领域
