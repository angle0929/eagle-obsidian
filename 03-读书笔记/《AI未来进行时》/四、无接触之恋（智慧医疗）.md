# 无接触之恋

2019年的新冠疫情让陈楠成为孤儿，同时也给她留下对疫情的阴影，让她只要出家门就没有安全感。疫情结束后的时间内，陈楠居家工作，从没有踏出过家门。陈楠在一款多人在线VR游戏“Techno Shaman”中交到巴西人加西亚，加西亚多次提出俩人线下见面，但是陈楠始终不能克服疫情给她带来的阴影而拒绝加西亚。加西亚为了帮助陈楠克服心理恐惧，和在"Techno Shaman"上认识的一名医生和一个愿意帮助像陈楠这种多年不出家门或者说是没有健康记录（主要从生物感应贴膜传感信息，没有生物感应贴膜的人在城市寸步难行）的人在城市中通行的马大叔一起布局，以加西亚自己在来新加坡的路上感染一种严重的传染病毒把陈楠引出家门，由马大叔一路护航带陈楠购买生物感应贴膜，并送至安排好的医院让陈楠和加西亚见面。路上，陈楠时刻注意着加西亚的健康信息（此时的生物监测都有人工智能负责，医疗AI生成报告将情况发送给患者家属），一路奔波下陈楠渐渐克服心理恐惧。

## 原句

- AI辅助的自动化放射科也能完成从拍片、看片到分诊的流程，大大减少了二度传染的风险
- 由AI分析病毒类型，进行蛋白质结构预测以制备相应药物与疫苗

# 开复解读

## 数字医疗与人工智能的融合

- 首先，现有的医疗数据和流程将实现数字化，一些科室（放射科、影像科）也可以实现数字化（人工智能通过计算机视觉技术看片）
- 个人病例和保险记录正在快速汇集成为巨大的脱敏数据库
	```
	这数据库结合AI可以精准追踪病情，判断医生水平，提高治疗效率、辅助医学教育和及早发现和预防疾病。
	```
- 药物使用的完整数据库将有助于医生和AI能够学习每种药物的适用使用条件
- 人工智能可以考虑到完整的病史和家族史

## 新技术的数字化

在医学研究中，突破性的新技术与生俱来即是数字化的。
```
e.g. 基因测序数据非常庞大，AI能够读懂，而人类无法阅读CRISRP是突破性的基因编辑技术，未来有可能根除许多疾病；药物和疫苗研发也正在走向数字化
```
但是人工智不能解决所有医学问题，人工智能医疗应该从哟个有打算数据集而且适合AI的较简单的任务开始
```
虽然每个癌症都可以帮助医生学会很多关键概念，在诊断的过程中库经过人类大脑分析和其他知识点的融合，用于每个病例，但是AI学习是经过海量数据而不是经过概念的，而AI需要的海量真实的患者实际的疗程和效果的数据-→短时间内，人工智能在癌症治疗方面发展阻力很大
```

## AI在蛋白质折叠、药物筛选及研发方面的能力

蛋白质是生命的基石。但是蛋白质的安吉苏安序列如何折叠成3D结构从而成为生命活动功能执行者的整个过程对于人类来说仍是一个迷
1. AI（e.g. AIphaFold）背后的训练数据集非常庞大，包含过去发现的所有蛋白质三维结构信息。目前AIphaFold已经被证明有模拟位置蛋白质三维结构的能力，相较于传统方法（e.g. 冷冻电子显微镜成像技术）更精确、更节时，成本也更低
2. AI可以通过发病机制搜寻已有的能够治疗疾病的药物实现“药物再利用”
3. 在三维结构上找靶点，然后提取相关信息并找到最佳的靶点分子
4. NLP技术可对海量学术论文、专利成果和公开数据进行深入挖掘，从中提取出能够帮助锁定靶点或者有效分子排序的信息

## AI与精准医疗及诊断

- 未来20年，在某种程度上所有手术都将包含机器人的参与，而由机器人圈圈负责的手术比例也将大幅提高
- 可穿戴设备将为AI在医疗领域的发展提供沃土。智能家具、智能移动设备都可以拥有采集user的生物数据的能力，集中式AI在未来会为人类的健康监护带来巨大便利

## 机器人技术

因为精度的高要求，在20年内，机器人技术很难完美地达到人类在视觉、触觉、操控、移动和协调等方面的水平，所以在短时间内，很难有手术机器人完全取代手术医生
```
手术中心电图等仪器产生的数据量也很庞大，可以用来训练专门监护患者生命状况的人工智能，取代麻醉医生手术期间的监护工作。同时，随着机器人技术的发展，机器人的精准度终有达到手术要求的时候，能够完成麻醉医生的插管之类的操作任务。到那时候，麻醉医生应该往哪方面发展。
律峰老师解惑：人工智能依靠已有数据、知识训练，不能产生新的知识。概念和技术创新还是要依靠人类的探索。科技创新能力将会是未来医生的重要能力，需要医生有坚实牢固、系统完整的知识基础。
```
