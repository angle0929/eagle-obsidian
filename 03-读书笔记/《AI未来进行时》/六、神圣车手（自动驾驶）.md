# 神圣车手

这是一个自动驾驶技术已经突破达到L5的时代，中国RealX公司在全球范围寻找顶尖驾驶员。恰马尔，来自斯里兰卡，在舅舅朱尼厄斯的推荐下被RealX公司选中前往深圳参加训练。一次巧合下，恰马尔发现“游戏”训练里的海啸救援任务是日本实事背景下的，任务失败的恰马尔也留下心理阴影，放弃训练回到斯里兰卡。后来知道真相，他们这些参加所谓游戏训练的人是在为将来自然灾害等特殊情况下下，自动驾驶技术失效时驾驶员紧急营救做训练。在回到斯里兰卡之后，恰巧遇到当地恐怖袭击，训练中心已经无人可以驾车去救援，只有恰马尔孤身一人前去营救，最后救出所有被困人员。

# 开复解读

驾驶过程：
1. 感知（眼看耳听）
2. 导航规划
3. 推理（预测行人、驾驶员的意图和可能的行动）
4. 决策
5. 车辆控制

## 自动驾驶分级

- L0（“无自动化”的人工驾驶）：人类驾驶员承担所有的驾驶任务，AI会观测道路并在必要时一行驾驶员
- L1（“人类不能放手”的辅助驾驶）：在人类驾驶员的允许下，AI可以完成特定的驾驶操作（e.g. 转向）
- L2（“人类放手”的部分自动驾驶）：AI可以承担多项驾驶任务，但人类驾驶员仍需要监控驾驶环境，并在必要时接管车辆
- L3（“人类移开视线”的有条件自动驾驶）：AI可以承担大部分驾驶任务，但需要人类驾驶员在AI遇到无法处理的情况并发出请求时接管车辆
- L4（“人类放松大脑”的高度自动驾驶）：AI可以在整个行车过程中完成接管车辆，但前提是车辆处于AI能够理解其状况并处理其问题的环境
- L5（“不再需要方向盘”的完全自动驾驶）：无论车辆处于何种环境，都不再需要人类驾驶员参与驾驶操作
```
L0-L3的自动驾驶已经在商用车辆上落地使用；部分L4自动驾驶车辆也在一些限定区域进行路测和实验；L5自动驾驶依然遥不可及
实现L5自动驾驶，AI系统需要针对大量的数据进行训练，而且这些数据必须来源于千变万化的真是驾驶场景
```

## L5自动驾驶将带来的影响

- 智能调度系统会用算法求出使自动驾驶车队空载率最小的最优解
- 据数据统计，美国人平均每周要在开车上花费8.5小时，而在未来的自动驾驶时代，人们将额外获得这8.5小时的宝贵时光
- 在自动驾驶车辆及技术、共享用车服务越来越成熟的同时，买车的人会越来越好（这实际上减少了家庭开支）

## 阻碍L5自动驾驶的非技术性难题

e.g. 一辆电车失控了，即将撞死A和B两人，作为驾驶员的你是否应该拉一下拉杆让失控的电车转换轨道，撞死另一条轨道上的C呢？如果C是个孩子呢？如果那辆车是你的车，而且C是你的孩子呢？
