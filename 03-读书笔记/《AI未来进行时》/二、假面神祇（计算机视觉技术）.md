尼日利亚是一个多民族的国家，拉各斯是约鲁巴人占据绝对主流地位的城市，主角阿玛卡则是到拉各斯寻找人生价值的东南省份的伊博人。在这里，人脸识别在这个城市相当普及（上班、交通……）。约鲁巴人想要让已经有一定社会影响力的有着费拉•库蒂的虚拟人FAKA参加总统竞选，一伊博人要求阿玛卡制作一个可以通过AI识别的FAKA的视频以干扰FAKA的竞选

# 开复解读

## 计算机视觉技术

### 功能

 1. 图像采集和处理
	 1. 采集：使用摄像头以及其他类型的传感器采集真实世界中的三位场景
	 2. 处理：每个图像都是一个二维矩阵，矩阵中的每个点都代表人所能看到的颜色（即”像素“）
2. 目标检测和图像分割：把图像划分成若干个不同的区域和物体
3. 目标识别：对物体进行识别并掌握更多的细节特征
4. 目标追踪
5. 动作识别：对动作和手势进行识别
6. 场景理解：对一个完整的场景（故事，事情）进行分析和理解，掌握其中复杂而微妙的关系

### 应用

1. 人脸识别、换脸技术：安检，区分士兵和平民，智能相机的人像模式，姿态识别（舞蹈游戏）
2. 对照片和视频进行只能编辑：美图秀秀等在计算机视觉技术的支持下没实现优化抠图、去红眼、梅花自拍等功能
3. 医学图像分析：CT
4. 内容过滤：社交媒体上的色情、暴力
5. 根据视频匹配相关广告
6. 智能图像搜索

### 基础——卷积神经网络（CNN）

1. 是什么
	1. 人眼看到外界事物时，大脑中的视觉皮层会调用很多神经元，这些神经元只接受与其所支配的刺激区域（感受野）的信号
	2. 类似于人脑感受野的滤波器，通过特征的识别来层层分类，每个滤波器的输出都是它所检测的特征的置信度
2. 作用原理：
	1. 卷积神经网络的架构有等级之分，每一层滤波器输出的特征置信度都将成为下一层滤波器的输入，提取更复杂的特征
	2. 以最大化目标函数未前提，自主决策每一层滤波器提取哪些特征

## 深度伪造（Deepfake）

### 生成式对抗网络(GAN)

1. 生成式网络
2. 判别式网络
```
判别式网络识别判断生成式网络生成的图像并将结果反馈给生成式网络，生成式网络通过反馈进行优化，两者在一次次博弈中携手升级，最终达到以假乱真的效果
```
3. 其他用途（利大于弊）
	1. 让静止的画面动起来
	2. 提高分辨率
	3. 检测青光眼
	4. 预测气候
	5. 发现新药
