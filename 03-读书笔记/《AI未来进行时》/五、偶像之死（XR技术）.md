# 偶像之死

狂热的粉丝不能接受偶像博嗣改变人设，集结成一股强大的力量攻击网络，因此引发了关于偶像与粉丝关系的社会讨论。舆论矛头也直指博嗣本人，在巨大的压力下，博嗣患了抑郁症，从此借助一次演唱会的假死自杀退出娱乐圈。20年后，一款由博嗣和太洋共同开发的“沉浸式游戏”以满足粉丝们对自己偶像人设的设定。爱子，曾经博嗣的粉丝，在这款游戏中不断寻找博嗣死亡的原因。爱子成功通过游戏后，博嗣和爱子在现实世界相见，博嗣将真相告诉爱子并且邀请曾为记者的爱子加入他们，希望爱子用自己的专业能力将每个故事讲的更真实。
- 尽管大脑明明知道它是假的，是设定好的剧情，可所有的细节，包括AI身影说话的语气、动作、与我交互的方式，都会让人忘了它是假的，全身心地沉浸在故事里。

# 开复解读

## XR技术

1. AR（Augmented Reality）
	1. 增强现实
	2. 通过计算机算法将文字、图像、3D模型、视频等虚拟信息叠加到真实世界的环境中
	3. 拥有“超现实”的感官体验
```
AR技术基于现实环境，需要先利用摄像头实时拍摄现实世界的环面，然后再把虚拟物体和虚拟内容（标记目的地，导航录像……）混合进去
```
2. VR（Virtual Reality）
	1. 虚拟现实
	2. 由计算机仿真系统生成的虚拟世界
3. MR（Mixed Reality）
	1. 混合现实
	2. 通过在虚拟环境中引入现实场景信息，在虚拟世界、现实世界和用户之间搭建起一个交互反馈的信息桥梁
```
MR所构建的虚拟场景并非虚拟信息的简单叠加，而是需要理解场景，通过在虚拟环境中引入现实场景信息，将现实世界和虚拟世界融合后产生一个新的可视化环境
MR要知道在现实世界中，该物体的作用、原理和使用方式等
```

## XR技术的挑战

1. 设备方面，要轻便（裸眼显示 and 脑机接口），同时只有降低成本才能实现大众普及
2. 数据安全及个人隐私问题
3. XR将使人类重新定义生命
