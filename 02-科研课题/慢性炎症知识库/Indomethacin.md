# Indomethacin（吲哚美辛）

| 字段 | 内容 |
|---|---|
| 靶点 | PPARG |
| 分子类型 | NSAID 直接配体；正构位结合并可共价修饰 Cys285 |
| 类型判定依据 | NSAIDs 激活 PPARγ（Lehmann 1997）；共晶+共价文献 |
| 结合位点氨基酸残基 | [PDB 3ADS共晶计算] His323/His449/Tyr473 + Cys285/Arg288/Ser289/Tyr327/Gly284/Gln286/Ile281/Ile326/Ile341/Leu330/Leu453/Met348/Phe282/Phe363 等 |

| 主要文献 | JBC 1997 NSAIDs activate PPARα/γ；Sci Rep 2015 (organotin paper 系列)；eLife 2025 covalent mechanisms |
