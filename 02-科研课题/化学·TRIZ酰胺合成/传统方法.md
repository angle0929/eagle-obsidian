# 反应条件

1. 温度：先0~5℃（活化羧基）再20~25℃$\rightarrow$温度调控复杂
2. 弱碱性，无水条件（中间产物易水解）$\rightarrow$ 干溶剂，昂贵
3. DCC：熔点低，腐蚀性，急性毒性；活化羧基，需要1.1~1.2当量
4. DCU：对水生物有害
5. 反应时间长：8h以上
6. 底物适应性较低：底物类型不同，选用溶剂不同
	1. 无水二氯甲烷 DCM：绝大多数小分子脂肪 / 芳香羧酸、胺
	2. 无水 DMF：极性底物、氨基酸、多肽、盐型羧酸盐
	3. 无水 THF：中等极性底物
7. 原子利用率低：投入反应的酸只有一半反应为酰胺
8. 中间体O - 酰基异脲不稳定，易分子内重排生成N - 酰基脲副产物
9. 副产物多：N - 酰基脲、二环己基脲（DCU）
10. 化工合成中，后处理复杂：
   反应终点控温析出 DCU→压滤脱除大部分 DCU→稀酸、弱碱、盐水多级萃取除碱性助剂、缩合助剂与未反应原料→减压回收溶剂得到粗品→溶剂打浆或重结晶脱微量 DCU 与 N - 酰基脲杂质→过滤、真空干燥得到酰胺成品；若为 DMF/DMSO 溶剂体系，需先脱除高沸点溶剂、溶剂置换后再析出过滤 DCU，后续萃取精制流程一致
	1. N - 酰基脲溶于有机溶剂，无法过滤除去，只能靠酸碱水洗 + 重结晶深度去除
	2. DCU颗粒微小，难彻底除去且DCU在 DMF、DMSO 里溶解度很大，没法靠简单过滤除去
	3. 常用 DMF、DMSO 高沸点极性溶剂，精馏回收能耗极高；二氯甲烷（DCM）属于管控 VOC 溶剂，防爆车间、废气治理投入成本高。
