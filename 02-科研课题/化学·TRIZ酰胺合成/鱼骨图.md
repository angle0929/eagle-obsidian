# 物料

- 成本高——DCC活化羧酸
- 副产物多——副反应多、中间体不稳定
- 干燥剂要求高——DCC和中间体极易水解

# 操作者与环境

- 安全风险——DCC对人体有致敏性
- 水环境污染——副产物DCU污染水体

# 装置设备

- 温控系统——活化子系统与酰胺化子系统温度不同
- 后处理复杂——副产物多且性质与目标产物接近
