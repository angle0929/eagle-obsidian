第一部分：问题描述

**1、项目概述**

**1.1项目来源**

是一种内源性非编码小分子单链，与基因在特定的时空中选择性表达密切相关，在生物体的发育、细胞分化、细胞的命运决定等方面发挥关键作用，影响多种生理和病理过程。其中，-的异常表达表现出了与心血管系统疾病及肺癌、肝癌等多种癌症肿瘤具有强相关性，是疾病早期诊断、病理分级、病程进展与预后评估的重要的分子标志物。

MicroRNA-24（miRNA-24）是一种内源性非编码小RNA，通过与其靶信使RNA（mRNA）的3'非翻译区（3'UTR）结合，介导转录后基因沉默，从而在细胞增殖、分化、凋亡及疾病发生等生命过程中发挥关键调控作用。特别地，异常miRNA-24表达在心血管疾病的意义得到了广泛的研究。如图1所示，其通过调控血管细胞与心肌细胞的核心功能，深度参与动脉粥样硬化、血管再狭窄及心力衰竭等关键病理进程。

在血管层面，miRNA-24通过靶向GATA2其PAK4等基因影响内皮细胞的增殖与迁移，调节血管生成及屏障功能。其对血管平滑肌细胞表型转换的调控尤为关键：通过抑制TRIB3等基因，miRNA-24驱动平滑肌细胞向合成表型转化，促进增殖与迁移，从而加剧血管新生内膜增生和动脉粥样硬化斑块发展，但同时也可能通过增强纤维帽稳定性而影响斑块破裂风险，展现出功能的双重性。在心肌层面，miRNA-24通过靶向促凋亡基因Bim发挥抗心肌细胞凋亡的保护作用，减轻心肌梗死后的组织损伤，并参与调控心脏成纤维细胞活化与纤维化进程。

因此，miRNA-24作为一个核心转录后调控枢纽，在心血管系统中的生物学意义呈现高度的复杂性与情境依赖性，其定量检测方法的建立与运用对心血管疾病的早期诊断和预后评估具有重要意义。

**1.2问题描述**

传统miRNA的检测方法主要依赖于Northern blotting、实时荧光定量PCR（qRT-PCR）和微阵列技术。Northern blotting作为早期金标准，能够提供miRNA大小和表达量的直接证据，但其灵敏度低、通量有限且需大量高质量RNA样本，难以应用于大规模筛查。qRT-PCR技术凭借其高灵敏度和特异性成为当前绝对定量的主流方法，其局限性在于茎环结构引物设计可能引入偏好性，且前体miRNA与成熟miRNA的区分需依赖特异性引物，在石蜡包埋组织等降解样本中检测准确性易受影响。微阵列技术虽能实现高通量并行检测，但其动态范围窄、灵敏度较低，且交叉杂交现象可能导致假阳性结果，通常仅适用于初步筛查而非精确定量。这些传统方法共同面临的核心挑战在于：难以对低丰度miRNA进行精准检测，无法在单细胞水平解析miRNA表达的异质性，且均需预先设计探针或引物，无法发现新型或未知miRNA。此外，现有技术多局限于核酸层面检测，无法直接反映miRNA与靶标结合的动态功能状态，这限制了对miRNA生物学功能的深入解析。

近年来，先进检测技术如数字PCR通过微滴分割实现单分子绝对定量，显著提升检测灵敏度与准确性；纳米孔测序技术则凭借无需扩增、实时读取单链RNA序列的特性，有效克服二级结构偏差并识别碱基修饰；表面等离子体共振成像技术通过无标记方式动态监测分子结合过程，为miRNA相互作用研究提供新维度，然而这些技术在临床转化中仍面临通量限制、设备成本高昂及数据分析标准化等挑战。

**1.3技术参数**

**1.3.1电致化学发光（ECL）生物传感器的设计**

电致化学发光（ECL）是一种利用光信号变化实现目标检测的技术，它通过在电极表面施加特定电压，使电活性发光物质经历氧化还原反应生成高能态中间体，其退激时释放出光子从而产生光信号。，如表1所示，ECL技术因高灵敏、低背景噪声和良好的稳定性在环境监测、食品检测、生物分析等领域得到了广泛的应用。

表1. 电致化学发光（ECL）生物传感器技术参数示意

|   |   |   |   |
|---|---|---|---|
|序号|技术参数|原理|意义|
|1|检测限|传感器能够可靠检测出的待测物的最低浓度或量|衡量灵敏度|
|2|检测范围|传感器信号与待测物浓度呈线性或可定量关系的浓度区间|进行生物标志物的定量分析，范围越宽，适用性越强|
|3|特异性|传感器在复杂样品中区分目标分析物与结构类似物或其他干扰物质的能力|提高抗干扰能力，增加结果可信度|
|4|线性|信号（如ECL强度）与分析物浓度之间的直接比例关系|确定可预测性，提高分析结果准确性和可靠性|

本传感器构建为ECL传感器，涉及材料选择、信号放大策略、及稳定性、特异性和线性评估的复杂过程，通过材料创新与方法优化的协同效应，拓展了该技术在生物检测领域的应用广度与深度。

**1.3.2基于有机框架材料的结构优势构建**

本传感器采用具有双晶相结构的双金属ZnRuMOF作为核心功能材料，其结构设计具有显著优势。该材料以Zn²⁺为金属节点、Ru(dcbpy)₃²⁺为有机配体，通过单斜相与立方相的共存实现了对氧还原反应路径的有效调控。独特的双晶相结构不仅提供了丰富的活性位点，还实现了对不同活性氧物种的选择性生成，为自电位分辨电化学发光奠定了基础。

在材料性能方面，ZnRuMOF的三维纳米花状结构赋予了其较大的比表面积，有利于反应物的吸附和电子传输过程。更重要的是，不同晶相结构对氧还原反应中间体的差异化吸附能力，使其能够选择性地产生活性氧物种，这一特性为构建单发光体比率型传感器提供了可能。

基于上述结构特点，该材料展现出多重优势：首先，将发光中心与催化位点整合于同一框架内，实现了分子内自催化，提高了能量利用效率；其次，双晶相协同作用实现了电位分辨的ECL信号输出，避免了传统方法中需要使用多种发光体的复杂性；此外，材料在生理相关pH条件下表现出良好的稳定性，为其生物传感应用提供了保障。

综上所述，双晶相双金属ZnRuMOF凭借其独特的结构设计和可调控的催化发光特性，为发展高性能电化学发光生物传感器提供了理想的材料平台，满足对miRNA等生物标志物的高灵敏检测需求。

本研究开发的电致化学发光（ECL）传感平台是基于先进功能材料构建的高性能检测系统，其构建策略与应用价值主要体现在以下方面：

在传感系统构建方面，该平台通过合理的分子工程策略，成功制备了具有双晶相结构的金属有机框架材料。这种材料设计不仅实现了发光体与催化位点的分子级协同，还通过晶体相调控实现了活性氧物种的选择性生成，为自电位分辨检测奠定了基础。传感器采用酶辅助信号放大策略，进一步提高了检测灵敏度。

在临床应用层面，该传感器在重大疾病标志物检测方面展现出独特优势。实验结果表明，该平台能够实现对心血管疾病关键标志物miRNA-24的超灵敏检测。这种高性能检测能力为疾病早期诊断、疗效评估和预后监测提供了新的技术手段，在精准医疗领域具有重要的实践意义。

**2、发明问题初始形势分析**

**2.1系统的工作原理**

**2.1.1 双晶相ZnRuMOF的构建与特性**

双晶相ZnRuMOF是通过配位自组装法制备的具有双功能特性的晶态多孔材料。在合成过程中，以Zn ([[#^comment-0|Comment Unknown Author 2]])为金属节点、Ru(dcbpy)3 ([[#^comment-0|Comment Unknown Author 2]])为有机配体，通过调控PVP导向剂的浓度实现单斜相与立方相共存的特异晶体结构。

该材料具有以下显著特性：三维纳米花状形貌赋予材料高比表面积，有利于电子传输与界面反应；独特的双晶相结构使其能够选择性催化氧还原反应生成不同活性氧物种（O₂·⁻与·OH），为实现自电位分辨ECL检测奠定基础；双金属协同效应通过Zn ([[#^comment-0|Comment Unknown Author 2]])的3d ([[#^comment-0|Comment Unknown Author 10]])电子配置稳定发光中心，同时Ru(dcbpy)3 ([[#^comment-0|Comment Unknown Author 2]])提供优异的电化学发光性能；模块化结构允许通过改变金属节点比例精确调控材料的ORR催化路径与ECL发射特性；材料在pH=6.0的缓冲体系中能展现的稳定ECL信号，证实其良好的电化学稳定性。

**2.1.2 自催化信号放大机制**

该ECL生物传感器采用分子内自催化信号放大策略。双晶相ZnRuMOF作为集成化发光-催化平台，其单斜相结构优先催化生成O₂·⁻促进阴极ECL发射，而立方相结构倾向产生·OH增强阳极ECL信号。这种分子内ROS生成机制显著缩短了电子传递路径，减少了自由基转移损失。同时，引入铂单原子催化剂（Pt-N-SACs）进一步优化ORR路径，通过调控·OH生成效率实现信号增强。结合双链催化杂交放大技术，通过目标miRNA-24触发级联反应实现核酸信号指数扩增，最终形成基于电位分辨的双信号输出模式，有效提高检测灵敏度与特异性。

**2.1.3 自电位分辨型ECL传感模式**

本研究构建的是一种基于自电位分辨机制的电致化学发光（ECL）生物传感器。该传感器的核心特征在于利用双晶相ZnRuMOF材料在不同施加电位下产生差异化ECL信号的特性，实现对待测物的定量检测。当目标物miRNA-24存在时，其通过催化发夹组装反应触发信号传导过程，引起电极界面ECL信号强度的规律性变化。传感器通过记录阴极与阳极电位下的ECL信号比值，建立与目标物浓度之间的定量关系，从而实现对miRNA-24的高灵敏检测。该自电位分辨设计避免了传统方法中需要使用多种发光物质的复杂性，为单发光体比率型生物传感提供了新的思路。

**2.2存在主要问题**

目前该传感器在实际应用中仍面临若干技术挑战。首先，其信号区分度相对有限，导致检测的灵敏度和准确性有待进一步提升。同时，信号输出的稳定性与强度尚不理想，检测范围和检测下限也较为有限。此外，传感器在复杂样品基质中的选择性有所下降，可能增加误报或漏报的风险。上述问题在一定程度上制约了该传感器在临床样本分析和医学诊断等领域的实际应用潜力。

**3.4.1系统描述工程系统**

电致化学发光检测系统是本实验的核心，旨在高效、精确地检测miRNA的分子特征。该系统利用金属有机框架结构作为发光探针，提供了灵敏度和准确性。在具体实施中，金属有机框架结构的使用可以显著增加电化学反应的表面积，从而增强信号强度。此外，系统使用核酸链作为生物识别分子，确保目标miRNA的特异性捕获，进而提高检测的选择性。

系统中的钌金属框架结构（RuMOF）作为重要组分，不仅增强了信号传导效率，还促进了电子转移过程。这一组件的设计至关重要，因为它能够有效提升光信号的发射，从而使检测变得更加灵敏。

在系统内部，各组件之间的相互作用十分关键。首先，金属有机框架通过增强电致化学发光反应，提供了有效的信号输出。而核酸链则通过与miRNA的特异性结合，确保只有目标分子产生信号，避免非特异性反应的干扰。这样的结构设计使得整个系统能够在极低的miRNA浓度下仍然保持高灵敏度的检测能力。

超系统组件则包括与实验操作及环境相关的外部因素。例如，操作人员的专业技能和知识对系统的有效运行有直接影响。为此，在实验过程中，操作人员应该经过充分的培训，以掌握设备的使用和数据的分析。此外，ECL检测与生物探测环境的设置也至关重要。确保实验在最佳条件下进行，如温度、湿度和光照等，可以大幅提高结果的准确性。

**（1）描述关键问题**

在当前假设下，我们决定降低该传感器的材料、技术成本，以实现高收入。在该假设下，由于技术限制，无法选择较好的核酸信号放大策略，因此我们考虑基于不同晶相金属有机框架对溶解氧ORR的选择性不同的双信号比率模式，通过催化选择性实现阴阳极信号强度选择性，用于miRNA-141的电致化学发光比率分析，也实现了较好的结果。

**方案一：引入单原子催化剂**

引入单原子催化剂（如Pt-SACs）到初代传感器中，利用其独特的催化性能和选择性来增强传感体系的活性氧浓度，从而增强电致化学发光（ECL）信号。单原子催化剂是金属以孤立原子形式锚定于载体上的催化材料。其特点在于活性位点高度均一，且金属与载体间存在强相互作用，形成独特的电子结构。核心优势包括：最大化原子利用率，近乎100%的金属原子参与反应；显著提升催化活性和选择性；减少贵金属用量，降低成本。该技术为高效催化反应提供了新范式，在能源转化和环境保护领域具有广阔应用前景。

**方案二：石墨烯图像传感器**

石墨烯图像传感器利用石墨烯的优异电学和光学特性，实现对光的高灵敏度检测。石墨烯是一种由碳原子以sp²杂化轨道组成的二维材料，具有高导电性、高透明度、机械强度和热导率。在图像传感器领域，石墨烯可以作为一种新型的光电探测器材料，因其独特的能带结构和载流子迁移率，能够实现快速的光生电荷载流子的产生和收集，从而提高图像传感器的性能。

**方案三：使用Zn金属盐和三联吡啶钌衍生物合成双晶相三维ZnRuMOF**

将传感器中的三联吡啶钌修饰为ZnRuMOF，这种双金属有机框架（MOF）材料具有更大的比表面积和更多的活性位点，有助于提高传感器的灵敏度和选择性。ZnRuMOF将Zn金属的催化位点和Ru的发光位点结合在分子内，实现“ORR-ECL”分子内反应，提高了ROS利用率。同时，结合形成的固体MOF具有好的稳定性，不会轻易分解释放重金属。通过改变金属的投料比，还可以调控MOF的纳米直径和晶相比例，间接调控电子结构和催化性能。

**方案四：使用金属盐和四配位三联吡啶钌衍生物合成2D-MRuMOF**

通过将2D-MRuMOF（M=Zn， Cu， Co， Ni）集成到混合基质膜中，可以提高有机溶剂纳滤的性能。这种集成方法利用了2D-MOFs的高比表面积、薄厚度和高灵活性，有助于制备具有增强选择性和与聚合物基质良好相容性的薄选择层。

**方案五：实现阴阳双极双信号比率发光信号策略**

通过集成双晶相的ZnRuMOF，实现在Zn节点在阴阳极分别选择性催化产生不同的ROS作为Ru节点在阴阳极ECL的共反应物，同时产生双极信号，利用两个发射信号的强度比值进行检测，其核心优势在于内置自校准功能，能有效消除背景干扰，显著提高检测的准确性与可靠性，特别适用于复杂环境下的精密分析。

**方案六：实现“ON-OFF-ON”信号转换策略**

“ON-OFF-ON”信号转换策略是一种核酸信号放大技术，用于提高传感器的选择性和灵敏度。这种策略通过设计特定的DNA探针，实现对目标分子（如miRNA-24）的检测。该策略包括三个阶段：初始的信号开启（ON），目标分子结合后的信号关闭（OFF），以及信号的再次开启（ON），从而实现对目标分子的高灵敏度检测。

|序号|存在问题|问题描述|
|1|光吸收效率问题|石墨烯本身吸收的光子很少，这是因为石墨烯虽然具有优异的导电性、柔韧性和透明度，但作为单一材料使用时，其对光的吸收能力较弱。相比之下，量子点能够极好地吸收光子，并将这些光子传递到石墨烯层，从而提高效率（光子到电信号的转换率约为60%）。|
|2|效率较低|尽管石墨烯和发光体结合的图像传感器在透明度和柔韧性方面表现出色，但其光子到电信号的转换效率（约60%）相较于传统的硅光电二极管（效率可达90%左右）还是较低。这意味着在相同条件下，石墨烯图像传感器可能无法提供与单原子催化剂传感器相同的信号强度。|
|3|制造成本和工艺复杂性|石墨烯图像传感器的制造可能需要额外的步骤来确保其性能，如在石墨烯上方集成发光体层，这可能增加了制造成本和工艺的复杂性。|
|4|稳定性和降解问题|MOF材料在替换过程中更容易降解，原因在于替换过程会破坏MOF的骨架，这可能影响传感器的长期稳定性|
|5|生产一致性问题|由于使用化学工艺来制造MOF，因此MOF的大小存在一定的内在变化，任何直径偏离都会引起催化和发光性能的变化。制造商必须谨慎控制工艺流程以避免此类情况，这对于小型制造商来说尤其困难，他们往往很难生产出一致的产品。|
|6|光生电荷重新结合问题|双金属MOF表面积大，且存在双晶相，可能导致众多缺陷——晶格缺陷可能导致在电子到达电极之前，光生电荷重新结合。在此情况下，最初到达的光子不会被电路检测到，从而减弱了最终到达相机处理器的信号。|

（1）立论依据

本传感器提供了一种基于三维的锌钌配合物金属有机框架纳米材料，并将其用于ECL发光体的构建中，借助核酸信号放大技术成功开发了针对miRNA‑24的高灵敏特异性ECL传感器，具有很高的检测灵敏度和准确性。

1）ECL分析技术的优势

电致化学发光（ECL）分析技术结合了电化学的高可控性和光分析的高灵敏度，这使得ECL在生物医学分析、临床检验和环境检测等领域有着广泛的应用。ECL技术不需要外部光源，因此背景噪声低，可以实现高灵敏度的检测。此外，ECL的信号与电化学反应直接相关，可以通过电位控制，从而实现精确的信号控制和分析。

2）三联吡啶钌衍生物化合物作为ECL发光体

三联吡啶钌衍生物因其独特的光学和电化学性质，被广泛研究作为ECL发光体。三联吡啶钌体系使其具有良好的双极发光能力，而其与金属离子的配位能力则可以进一步改善发光体的光学性能。在本发明中，通过将三联吡啶钌衍生物与低毒性金属（如锌）结合，形成配位聚合物，既保持了结构的稳定性，又提高了发光效率。具体三联吡啶钌衍生物在阴阳极发光作用原理如图33。
