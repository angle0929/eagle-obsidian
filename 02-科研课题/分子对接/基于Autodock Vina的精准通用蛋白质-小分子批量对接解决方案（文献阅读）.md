# 提升vina的对接性能

vina在对接能力排名第一，但是其评价能力、排序能力、筛选能力等不尽人意
深度学习方法更擅长口袋搜索而非对接本身
1. 优化Vina评分函数中的拟合参数
2. 结合多种评分函数或评估不同评分结果的一致性
3. 采用基于机器学习的评分函数替代Vina的评分函数
4. 为特定类型的配体或受体构建评分函数
以上四大方法究主要集中在对接方法的改进上，忽视了对接参数对最终结果准确性的影响
